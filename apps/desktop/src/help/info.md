## parameters パラメータ

行を押してパラメータを選び、その値で形を直すとキーになる。●は代表のキー、○は中間のキー、■はロックしたキー。

- 行を選ぶと、ほかのパラメータの値は既定値に戻る。Ctrl＋クリックで組み合わせのキーを編集するときは、ほかの値を残す
- 行を選ばずにスライダーを動かすと、見え方を確かめるプレビューになる
- 行を選んでいる間は、正面0などの既定値も独立したキーとして直す。行を選ばずに形を直すと、基準の形が変わり、すべてのキーが一緒に動く。不透明度は既定値で基準の値を直す
- 既定値の形を元に戻すには、キーの印を右クリックして［このキーの差を消す（基準の形に戻す）］。キーの位置は残り、Undoで戻せる

1. 行を押して、編集するパラメータを選ぶ
2. スライダーの印や数値で姿勢を決める
3. キャンバスでパーツや頂点を動かして、その姿勢の形を直す
4. 代表のキーを作ったら［間を生成］。途中の値も必要に応じて直す

## parameters.generateBetween 間を生成

編集中のパラメータの、代表のキー（●）の間に中間のキー（○）を作る。生成方式は変えない。

- 両端のキー（例: −30と＋30）を作ったあと、途中の値（例: ＋10）の形も直したいときに使う
- 線形なら、作る前後で見た目は変わらない。キーの間はもともとまっすぐ補間される
- 回転・なめらか・曲面では、その方式に沿った中間の形を作る
- パーツを選んでいれば、そのパーツと子のキーだけに掛かる。選んでいなければ、編集中のパラメータを使うすべてのパーツが対象
- 手で直した代表のキーとロックしたキーは残し、未ロックの中間キーを作り直す

## parameters.regenerateAll すべて再補間

ロックしていない中間のキー（○）を、現在の生成方式で作り直す。

- 代表のキー（●）を直したあと、間の○が古い形のままのときに使う
- 全範囲に掛けた結果は［間を生成］と同じ。初めて中間キーを作るときは［間を生成］、直したあとに整えるときは［すべて再補間］が目安
- 印をShift＋ドラッグで囲むと、その範囲だけを再補間できる
- 残したい中間キーは手で直す（●になる）か、右クリックでロックする
- パーツを選んでいれば、そのパーツと子が対象。選んでいなければ、編集中のパラメータを使うすべてのパーツが対象

## parameters.rebuildDepth 奥行きで作り直す

頭の中の画像パーツの奥行きから、顔の左右・上下の向きのキーを作り直す。

- 前髪や後ろ髪などの奥行きを変え、自動の顔の向きを作り直したいときに使う
- ロックしていないキーは、手で直したものも作り直される。残したい形は先にロックする
- 手で直した既定値の形は保ち、新しく作るキーにもその補正を重ねる。残す手動キーに二重には重ねない
- 選んだパーツだけに絞る操作ではない。頭の対象パーツ全体に掛かる
- 1回のUndoで作り直す前に戻せる

## parameters.generation 生成方式

キーの間の形の作り方を選ぶ。方式を変えると、その方式でキーを作り直す。

- 線形: 両端のキーをまっすぐ混ぜる。ふつうはこれ
- 回転: 頂点・制御点を回転中心のまわりの円弧で動かす。腕や髪を振る形を頂点で作ったとき、途中で縮みにくくなる
- なめらか: キーの近くでゆっくり、真ん中で速く変わる。まばたきや口の開け閉め向き
- 曲面: 顔の向きのワープを球面に沿って作り直す。顔の左右・上下で使う。未ロックの手編集キーも作り直されるため、残したいキーは先にロックする
- 曲面の作り直しも、手で直した既定値の形は保ち、新しく作るキーへ補正を重ねる
- 方式の変更は、編集中のパラメータを使う全バインディングに掛かる。選択パーツだけに絞る操作ではない

## mesh メッシュ

画像パーツに網（メッシュ）を張り、頂点を動かして形を細かく曲げる。パラメータを編集中なら、その値のキーに記録する

1. キャンバスで画像パーツをクリックして選ぶ
2. メッシュが無ければ［自動生成］
3. 頂点をドラッグして動かす。何も無い所からのドラッグで囲んで選ぶ（Shift で追加）
4. ダブルクリックで頂点を追加、Delete で削除
5. 右クリックで選択を外し、別のパーツを選ぶ

## curveGuide 流れ線

髪などを一本の線で滑らかに曲げる。重力に沿わせ、選んだ対象だけ流れ揺れをONにすると遅れと余韻が付く。パーツの設定の軸揺れとも併用できる

1. キャンバスで髪のパーツをクリックして選ぶ（先にメッシュを自動生成しておく）
2. ［流れ線を描く］を押し、根元から毛先へドラッグ
3. 中間・毛先の点をドラッグして形を整える
4. 必要なら［重力に沿わせる］を有効にし、影響幅と頭について回る区間を調整する
5. 揺らしたい対象だけ［流れ線で揺らす］をONにし、［動きを試す］で確かめる
6. 右クリックで選択を外し、別のパーツを選ぶ

## warp ワープ

画像パーツやグループに格子を掛け、少数の制御点で絵を曲げる（顔の向き、髪や腕の調整など）。1枚の画像にも直接付けられる

1. キャンバスでパーツをクリックする。画像自身の格子があればその画像、無ければ格子があるいちばん近い親、どちらにも無ければその画像を選ぶ。［対象を変える］で画像や親を選び直せる
2. 格子が無ければ分割を選んで［ワープを追加］
3. 制御点をドラッグして動かす。何も無い所からのドラッグで囲んで選ぶ（Shift で追加）
4. パラメータを編集中なら、その値のキーに記録する
5. 右クリックで選択を外し、別のパーツを選ぶ

- 新しい格子は基準の姿勢で画面の横向きに合わせる。親の拡縮や既存ワープ、パラメータでの傾きは一緒に掛かる
- 既存の格子は［格子をまっすぐにする］で向きを合わせる。曲げた形には近似のずれが出るため、確認した姿勢の最大ずれを表示する。1回のUndoで戻せる

## contourLine 輪郭線

輪郭のように折れてほしくない所に線を引き、線の点を動かしてメッシュを滑らかに変形する。動きは今のキー（基準状態なら基準の形）に記録する

1. キャンバスで画像パーツをクリックして選ぶ（先にメッシュを自動生成しておく）
2. 輪郭をなぞる（そのままドラッグ。点を順にクリックして引くときは［線を引く］を押してから）
3. ［線に沿って頂点を足す］を押す
4. パラメータの値を選び、線の点をドラッグする
5. 段々が残っているキーは［線に合わせて整える］を押す

## setupTools.closedLine 閉じた目の線

まばたきで目を閉じたときのまぶたの形を決める。線は、閉じたときのまぶたの下の端。絵の上の位置で保存され、回転や動きについてくる

1. 目のパーツ（白目・上まぶたなど）を選ぶと、このパレットが出る
2. ［線の案を作る］か［閉じた目の線をなぞる］で、目の端から端まで線を作る。［点を動かす］で調整できる
3. ［この目のまばたきを作る］を押す。選んだ目の開閉だけを作り直す。手修正・ロック済み・笑顔との組み合わせキーは、確認してから置き換える
4. ［閉じ具合］を動かして確かめる。上まぶたと白目の割り当て、メッシュが必要。作れない理由はパレットに表示する。反映は1回のUndoで戻せる

## animation.startFromCurrent 現在の姿勢から再生

スタジオで再生する瞬間の姿勢を始点に、記録したトラックの変化量を重ねる実験設定。たとえば記録が顔の向き0→10なら、開始時が15のとき15→25へ動く。可動範囲の端では動きが小さくなる。開始時の姿勢は保存されず、再生するたびに取り直す

1. 登録の設定で［現在の姿勢を始点にする（実験）］をONにする
2. スタジオで表情やトラッキングを使って姿勢を作り、［今の姿勢から］と表示されたボタンで再生する
3. ［始まり］の秒数で動き始めをなじませる。［上書き］は開始の姿勢を基準に動き、［トラッキングに加算］はその後の顔・体の入力にも追従する
4. リップシンクや物理を維持しない場合は直前の形を保持して停止する。止めると［終わり］の秒数で現在の入力へ戻る。ループは元のトラックの繰り返しで、差が蓄積することはない
5. タイムラインの再生・アニメーション素材の書き出し・周期アニメーションは記録した値を使う。この設定はスタジオの通常のアニメーション再生に使う
