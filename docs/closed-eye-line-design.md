# 閉じた目の線を使えるようにする（設計）

2026-10-12 CL。ユーザーの指摘（課題は I-090）。操作性優先と次の実装指示に基づき、COがD1〜D7の推奨を採用して3段階を実装。契約はCC-022、保存形式は9。以下の現状分析は実装前の記録。

## 解決したいこと

ユーザーの言葉:

> 閉じた目の線の形の機能はうまく機能していない。正しい使い方もよくわからない。もっと使えるようにしてほしい。

1. なぞった線のとおりに、目が閉じるようにする（今はずれる）。
2. 何をなぞればよいか、なぞった後どうなるかが、画面で分かるようにする。
3. ほかの設定（手で直したキー・回転の中心など）を壊さずに、その目のまばたきだけを作り直せるようにする。
4. 閉じた形の質を、ユーザーの基準（まぶたと白目がどの値でもそろう、閉じたときに白目が見えない、目尻の折り返しはまっすぐ細くなる線）に合わせる。

## 今の作り（コードで確かめたこと）

| 項目         | 今の作り                                                                                                                                                                                                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 出る所       | 目のパーツ（白目・上まぶたなど）を選ぶと、右の列の上に「閉じた目の線」が出る（I-065）                                                                                                                                                                                                 |
| なぞる       | ［閉じた目の線をなぞる］→ キャンバスで目の端から端までドラッグ → 離すと保存して元のツールに戻る（`setupTools/closedLineTool.ts`）。保存した線は、なぞっている間しか描かない                                                                                                           |
| 保存         | `Model.setupHints.closedLineL/R`。**見えている位置（キャンバスの座標）**のまま、x で並べて保存する                                                                                                                                                                                    |
| 反映         | ［かんたんセットアップで反映］で、**かんたんセットアップ全体**をやり直す（`assets/actions.ts`）。階層・回転の中心・描く順・マスク・パラメータ・顔の向き・すべての自動のキー・呼吸・胸揺れまで作り直す。標準パーツの回転の中心は、決まった位置に置き直す（`core/src/setup/pivots.ts`） |

### うまく働かないわけ

1. **座標が合っていない（いちばん大きい）**: 線は見えている位置で保存するが、計算はメッシュの元の位置（親の回転・移動・キーを掛ける前）と比べる。ユーザーのモデル（cardigan）は頭のグループを約 8° 回し、目のグループも回しているので、線が 10〜15px ずれ、約 8° 傾いた所で閉じる。パラメータの値を動かした姿勢でなぞっても、ずれる。
2. **反映が重すぎる**: かんたんセットアップ全体をやり直すので、手で直したモデルでは回転の中心などまで置き直される。そのため押しにくい。
3. **黙って効かない場合がある**: 目にメッシュが無い、上まぶたの閉じ方（位置のキー）を手で直している、EyeOpen 0 に手で直したキー・ロックしたキーがある、のどれかだと、線は使われない（知らせも無い）。白目だけ作り直されて、まぶたとずれることもある。
4. **何をなぞるかが分かりにくい**: ⓘ は「閉じた目のまつげの線」とあるが、計算は「上まぶたの下の端」を線に合わせる。なぞった後に線が見えず、閉じた形も、反映して EyeOpen を動かすまで見えない。
5. **形の質**: まぶたの帯の厚みが一定なので、目尻の細い所が太くなり、折り返しがつぶれる。メッシュが粗いと、白目が頂点の間から見える。下まぶたは残ったまま。

ユーザーのモデル（`projects/cardigan-bob-20261010/build.ts`）で手で作ったまばたき（ユーザーが良いとしたもの）は、絵の不透明な所から上まぶたの下の端を求め、白目の上の端を一緒に動かし、目尻はまっすぐ細くなる線に置き換え、下まぶたも白目の下の端について行って薄くなり、細かいメッシュ（5px）を使っている。

## 考え方

### 第1段階: 線のとおりに閉じ、使い方が分かるようにする

- **線の持ち方**（D1）: 線を、白目（無ければ上まぶた）のメッシュの「絵の上の位置」で持つ（輪郭線と同じやり方）。なぞった点を、今見えているメッシュの三角形の中の位置から、元の位置に直して保存する。親の回転・移動・ワープ・今のキーがあっても、なぞった所で閉じる。今ある線（見えている位置のもの）は、開いたときに、基準状態で直して移す。
- **何をなぞるか**（D4）: 「目を閉じたときの、まぶたの下の端（閉じた目の線）」とはっきり書く。キャンバスには、なぞる前に今の上まぶたの下の端と白目の形を点線で出す。
- **いつも見える線**: 目のパーツを選んでいる間、保存した線を、今の姿勢のメッシュの上に描く。
- **閉じた形を見る**: パレットに「閉じ具合」のつまみ（EyeOpen の値。0 で閉じた目）を置き、反映した結果をその場で見られる（パラメータのパネルまで行かなくてよい）。
- **その目だけ反映する**（D2）: ［この目のまばたきを作る］を置き、その目の EyeOpen のキー（上まぶた・まつげ・白目・下まぶた）だけを作り直す。かんたんセットアップ全体はやり直さない。1回の Undo で戻る。
- **今あるまばたきのキー**（D3）: 手で直したキー・ロックしたキー・EyeOpen と EyeSmile の組み合わせのキーがあると、確認を出して「置き換える／やめる」を選ぶ。黙って重ねない。
- **効かないときは知らせる**: メッシュが無い・上まぶたか白目を割り当てていない・線が白目と重ならない・線が上まぶたより上にある、をパレットに出す。

### 第2段階: 閉じた形の質を上げる（D5）

ユーザーのモデルで手で作ったまばたきの作り方を、自動にする。

- 上まぶたの帯の厚みを、列ごとに絵の不透明な所から求める（一定にしない）。目尻は、まっすぐ細くなる線に置き換える。
- EyeOpen の 0・0.25・0.5・0.75・1 で、上まぶたの下の端と白目の上の端がそろうようにする（途中で白目がはみ出さない）。
- 下まぶたは白目の下の端について行き、閉じたときは薄くする。
- 線に沿って、目のメッシュに頂点を足す（輪郭線の［線に沿って頂点を足す］を使う）。
- 確かめは、EyeOpen を 0.05 ごと・顔を左右 ±30 に向けた絵で行う（ユーザーの確認の仕方）。

### 第3段階: なぞらなくてもよくする（D6・D7）

- 目の開いた所（白目の形）から、閉じた目の線の案を自動で作る（ユーザーのモデルでは、開いた所の高さの 82% の所）。なぞるのは、案が合わないときだけ。
- 線の点をドラッグして直せる（輪郭線と同じ操作）。

## 保存の形と契約（CC-022）

- `Model.setupHints.closedLineL/R` を、見えている位置の点の列から、`{ partId, points（絵の上の位置） }` にする。今の形は読み込みで移す（基準状態で直す）。schemaVersion を上げる。
- その目だけのまばたきを作る口を、`AutoSetup` に足す（`blink(model, side)` など）。
- `docs/contract-changes.md` に書く。

## テストと確認

- 単体: 回したグループの中の目で、なぞった線のとおりに閉じる（ずれ 1px 以内）。キーの値でなぞっても同じ。古い線の移し替え。その目だけ作り直し、ほかの目・口・回転の中心が変わらない。手で直したキーがあると確認が出る。効かない場合の知らせ。
- 第2段階: EyeOpen 0.05 ごとに、上まぶたの下の端と白目の上の端の差、閉じたときに見える白目の画素の数（0 になる）、目尻の折り返しの形。
- 画面: サンプルモデルと、ユーザーのモデルの写し（`projects/cardigan-bob-20261010` は直接触らない）で、なぞる → 閉じ具合のつまみ → 作る、の画像。

## 完成の条件

- 回したグループの中の目でも、なぞった線のとおりに目が閉じる。
- パレットだけで、なぞる・閉じた形を見る・その目のまばたきを作る、ができ、ほかの設定は変わらない。
- 効かないときは、理由がパレットに出る。
- （第2段階）どの値でも、まぶたと白目がそろい、閉じたときに白目が見えず、目尻はまっすぐ細くなる。
