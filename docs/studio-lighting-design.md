# スタジオの照明（設計）

2026-10-12 CL。ユーザーの要望（課題は I-081）。大きな機能なので、末尾の「決めてほしいこと」の答えをもらってから、段階に分けて実装する。

## 解決したいこと

ユーザーの言葉:

> スタジオに照明機能を作りたい。光源を設置することで、イラストの影になりそうな部分を推定して影を落とすようなイメージ。動的に計算できるとよい。事前にモデルをAIに読ませて、かげの位置を推定させるような感じでもいい。

これを、次の3つにまとめる。

1. スタジオのシーンに光源を置き、向き・強さ・色を変えられるようにする。
2. 光源の向きに合わせて、イラストの影になりそうな所を暗く、光の当たる所を明るくする。動かしても（顔の向き・光源の移動）その場で計算し直す。
3. 影の形を決める手がかり（パーツの丸み・奥行き）は、モデルから自動で求める。足りなければ、作るときに AI で補えるようにする（実行中はネットにつながない）。

## 考え方

### 光の当て方: パーツの「面の向き」を自動で作り、描くときに光と合わせる

1. **面の向き（法線）の絵を、パーツごとに自動で作る**（プロジェクトを開いたとき・素材を差し替えたときに作り、プロジェクトのフォルダに覚える）。
   - 絵の不透明な所の縁からの距離で、ふくらんだ形（まくら形）にする。腕・首・髪の房など、どのパーツにも使える。
   - 顔・肌は、頭の形の楕円（`HeadShape`）の面の向きを使う。顔の向き（FaceAngleX・Y）に合わせて回す。
   - 目・口の中・ハイライトなど、光を受けないパーツは除く（パーツの種類で決め、パーツの設定で変えられる）。
2. **描くときに、光の向きと面の向きの角度で明るさを決める**。アニメ塗りに合うよう、明るい所と影の2段（境目を少しぼかす）にする（D2）。影の色は、光の色の反対の色を少し混ぜた乗算（肌が灰色にならないように）。
3. **パーツどうしの影**（第2段階）: 前髪が額に、あごが首に落とす影。手前のパーツ（奥行きの大きいもの）の形を、光と反対の向きへ奥行きの差だけずらして、後ろのパーツに乗算で重ねる。重ねるのは、後ろのパーツの不透明な所だけ。
4. **ふちの光**（第3段階）: 光源が後ろ・横にあるとき、光の側の輪郭を明るくする（リムライト）。

```
光源（左上）
  ☀
    ↘
      ┌──────────┐   明るい側 ── 光の向きを向いた面
      │ ░░       │   影の側 ──── 光と反対を向いた面（2段の塗り）
      │ ░░░    ▓▓│
      │  ░░  ▓▓▓▓│   前髪の影 ── 前髪の形をずらして額へ（第2段階）
      └──────────┘
```

### 光源の置き方（スタジオ）

- シーンごとに光源を1つ持つ（`Scene.lighting`。D3）。項目: 使う・使わない、向き（画面の上の角度）、高さ（正面からの角度）、強さ、影の濃さ、光の色、環境光（影の側の明るさ）。
- シーンのパネルに「照明」の節を足す（背景・表情・配置の下）。数値に加えて、スタジオのプレビューで光源の印（☀）をドラッグして向きを変えられる（D4）。
- 光源は画面（シーン）に固定する。顔を左右に向けると、顔の面の向きが変わるので、光の当たり方が変わる（D7）。

### 出力

- スタジオのプレビュー・出力の窓・Spout2 で同じ絵にする（D8）。WebGL と D3D11（Rust）の両方のシェーダーに同じ計算を足し、今の「両方の絵が合う」テストに照明の場合を足す。
- Canvas 2D の予備の描画では照明をしない（今もメッシュとマスクを描けない）。
- 照明を使わないシーンの絵は、今とまったく同じにする。

### AI で補う（任意。第4段階）

自動の面の向きは、髪の房の重なりや服のしわを知らない。足りないときに、作るときに AI で補えるようにする。

- やり方: 元の立ち絵を ChatGPT の画像生成に渡し、「左上から光を当てたときの影の範囲」を白黒で描かせ、パーツごとに切り分けて「影の手がかり」の絵としてプロジェクトに入れる（パーツの絵の生成と同じ手順。実行中は使わない）。
- 描くときは、自動の面の向きと AI の影の範囲を混ぜる（AI の絵が1方向分しか無いので、光の向きがその方向に近いときに強く効かせる）。
- アプリの中で AI を動かす（深度の推定のモデルを同梱する）案もあるが、大きく、アニメ絵では精度が低いので、今回は採らない。

## 保存の形と契約（CC-018）

- `Scene.lighting?: { enabled, azimuth, elevation, intensity, shadow, color, ambient }`（省略は照明なし）。`Part.lighting?: 'auto' | 'none'`（光を受けるか。省略は種類で決める）。schemaVersion を上げる（足すだけの移行）。
- `Renderer.render` と `OutputSink.submit` に照明の引数を足す。出力の窓へのメッセージと Spout2 の送る形（SPF1）にも照明を足し、版を上げる。
- 面の向きの絵は、プロジェクトのフォルダの `cache/normals/` に置く（無ければ作り直す。消しても困らない）。
- `docs/contract-changes.md` に CC-018 として書く。

## テストと確認

- 単体: まくら形の面の向き（縁で外向き、中央で正面）、頭の楕円の面の向きが顔の向きに合わせて回る、光の向きと明るさの計算、照明なしのシーンの絵が今と同じ。
- WebGL と D3D11 の絵の比較（今の仕組み）に、照明ありの場合を足す。
- 性能: 照明ありで、スタジオの平均と 1% の遅いフレームを、今の計測（`docs/measurements`）と同じやり方で測る。
- 画面: サンプルモデルとユーザーのモデル（写し）で、光源を左上・右・後ろに置いた絵と、顔を左右に向けた絵を残す。OBS（Spout2）でも同じ絵になることを、ユーザーに見てもらう。

## 完成の条件（第1段階）

- シーンに光源を置き、プレビューで光源の印を動かすと、その場で影が変わる。
- 顔を左右に向けると、顔の影の位置が変わる。
- プレビュー・出力の窓・Spout2 で同じ絵になる。
- 照明を使わないシーンは、今と同じ絵・同じ速さ。
