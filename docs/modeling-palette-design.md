# モデリングのツールとパレットの整理（設計）

2026-10-08 CL。ユーザーの要望（課題は I-065）。末尾の「決めたこと」で設計を確定し、同日に実装した（契約の変更は CC-012、記録は docs/status.md、確認点は CH-179〜183・UC-CH-37）。実装で設計から変えた点は「実装で決めたこと」に書く。パレットの子ウィンドウ化は「子ウィンドウ化の検討」に分け、今回の実装には入れない。

## 解決したいこと

ユーザーの要望を、そのまま並べる。

1. 「閉じた線のなぞり」が目のためのツールだと分からない。名前に目を入れ、ⓘ ボタンで目的と流れの概要を見られるようにしたい。
2. パーツ専用のツールは、そのパーツのパレットに置きたい。上のツールバー（共通の場所）にあると、どのパーツにも使えると思ってしまう。目の線は、目を選んだときに出るパレットでよい。
3. ワープは「グループを選んでからツールを使う」ではなく、ツールを選んだらグループを選ぶ必要があることを、見て直感的に分かるようにしたい。
4. メッシュ編集中に右クリックでパーツの選択を外したい。拡大して目を編集中に誤って顔を押すと顔のメッシュに切り替わる。目を選び直すには、体などの別のパーツを選んで顔を外してから目を押す必要があり、手間がかかる。
5. パーツなどが何も無い所をクリックしたら、選択を外したい。
6. メッシュや流れ線のような「ツールの設定のパレット」は、そのツールを選んだときだけ出したい。
7. パレットを「共通パレット」と「オブジェクトパレット」に分けたい。目を選ぶとオブジェクトパレットに閉じた目の線、流れ線ツールを選ぶと流れ線の設定が出る。見出しの色を少し変えて見分けやすくする。

## 考え方

### 1. 共通パレットとオブジェクトパレット

- **共通パレット**: いつも出るもの。パラメータ、Transform、パーツの設定、標準パーツの割り当て、表情、母音（左の列の素材・パーツも共通）。
- **オブジェクトパレット**: 状況に合わせて出るもの。次の2種類がある。
  - **ツール**: そのツールを使っている間だけ出る（メッシュ、流れ線、ワープ）。
  - **パーツ**: そのパーツを選んでいる間だけ出る（閉じた目の線）。
- **列は増やさない。** オブジェクトパレットは、今ある右の列（幅 280px）の中の**いちばん上**に、共通パレットと同じ形で並べる。別の列・浮いた窓・キャンバスに重なる窓にはしない。キャンバス（作業エリア）の幅と高さは、今と変わらない（2026-10-08 ユーザーの指示: 別の列にして作業エリアを圧迫しない）。
- 見出しに薄い色を付け、右端に「ツール」「パーツ」の小さな札を付ける。状況が変わると現れたり消えたりするので、目に付く位置に出す。
- オブジェクトパレットは縮めない（中身をすべて出す）。足りない高さは共通パレットが分け合い、それでも足りなければ右の列の中をスクロールする。

### 2. 対象のあるツールは「対象を選ぶ → 編集する」の2段にする

メッシュ・ワープ・流れ線のツールには、どれも対象が要る（画像パーツまたはグループ）。そこで3つとも同じ流れにする。

- **対象を選ぶ段**（対象が無いとき）: キャンバスの上の中央に、帯で次の手順を出す（例:「① キャンバスでパーツをクリックして、ワープを付けるグループを選ぶ」）。マウスの下にあって選べるもの（ワープならグループ）の範囲を点線で囲み、名前を出す。クリックすると、それを選ぶ。
- **編集する段**（対象があるとき）: 今までの編集の操作。右クリックで選ぶ段に戻る。

この2段の仕組みは枠（CanvasHost）が受け持つ。各ツールは「対象が何か」と「クリックしたパーツから何を選ぶか」だけを決める。そのため3つのツールで同じ見た目・同じ操作になり、CO が担当した流れ線のツールも、押したときの処理を書き換えずに済む。

### 3. 選択の外し方をそろえる

| 操作                         | 選択・変形                     | メッシュ・ワープ                                                        | 流れ線                                       | 閉じた目の線をなぞる                                     |
| ---------------------------- | ------------------------------ | ----------------------------------------------------------------------- | -------------------------------------------- | -------------------------------------------------------- |
| 右クリック（動かさずに離す） | パーツの選択を外す             | 頂点・制御点とパーツの選択を外し、選ぶ段に戻る                          | パーツの選択を外し、選ぶ段に戻る             | なぞるのをやめ、元のツールに戻る                         |
| 何も無い所のクリック         | パーツの選択を外す（今と同じ） | 1回目は頂点・制御点の選択を外す。それが無ければパーツの選択を外す（D2） | 今のまま（クリックは線を描く操作に使うため） | —                                                        |
| Esc                          | パーツの選択を外す（今と同じ） | 何も無い所のクリックと同じ2段（D2）                                     | 今のまま（描きかけを取り消す）               | なぞりかけを取り消す。なぞっていなければ元のツールに戻る |

- 「何も無い所」は、ロックしていない画像パーツに当たらない所。編集中のメッシュの内側は「何も無い所」に含めない。
- 右ドラッグは何もしない（動かしたら右クリックとみなさない）。中ボタンとスペースでの移動は今のまま。
- 右クリックでメニューは出さない（今もブラウザのメニューを止めている）。

## ツールごとの詳細

### 閉じた目の線（パーツのパレット）

- ツール名を「閉じた目の線をなぞる」に変え、ツールバーから外す。パレットのボタンからだけ使う。
- 「目のパーツ」は、選んだパーツ自身か祖先の標準パーツの種類が、白目・瞳・ハイライト・上まぶた・下まぶた・目（まとめて）・目のグループ（それぞれ L/R）のもの。自由パーツでも、目のグループの中にあれば目とみなす。
- 出すのは**選んだ目の側だけ**（例:「目 L（画面の右）」）。キャンバスで目を押して選ぶので、L/R を名前で選び分ける必要が無くなる。両目を選んでいるときは両方の行を出す。
- ［閉じた目の線をなぞる］で、なぞるツールに切り替える。1本なぞって保存できたら、元のツールに自動で戻る。右クリック・Esc でやめても元のツールに戻る。なぞっている間は、目以外を選んでもパレットを出したままにする。
- パレットに［かんたんセットアップで反映］を置く（D4）。押したときの処理は、標準パーツの割り当ての［かんたんセットアップ］と同じ。
- なぞっている間の重ね描き（保存した両目の線を描き、なぞる側を強調）は今のまま。キャンバスの上には案内の帯で「目 L の閉じた線を、目尻から目頭までドラッグ（Esc でやめる）」を出す。

### メッシュ（ツールのパレット）

- メッシュ編集ツールのときだけ出す。［メッシュ編集ツールにする］は要らなくなるので外す。
- 選ぶ段: 帯に「メッシュを編集する画像パーツをクリック」を出す。マウスの下の画像パーツを点線で囲む。
- 編集する段: 今の操作のまま。右クリックで頂点とパーツの選択を外し、選ぶ段に戻る。何も無い所のクリックと Esc は D2 のとおり。
- メッシュの外で別のパーツを押したときの切り替えは D1 で決める。
- ツールを切り替えるとパレットが出し直しになり、頂点の選択は外れる（今もパネルを出し直したときに外している）。

### ワープ（ツールのパレット、詳細のみ）

パーツの設定にあるワープの節を、新しい「ワープ」のパレットへ移す。手順を番号付きで並べ、済んだ段には ✓ を付ける。

```
▌▾ ワープ                       ツール  ⓘ
  ① グループを選ぶ ✓   対象: 顔のグループ
     対象を変える: [顔のグループ（格子あり）▼]
  ② 格子を追加   ✓   格子 4×4（制御点 25）  [ワープを削除]
  ③ 制御点を動かす    選んだ制御点: 3 個
     制御点をドラッグ。何も無い所からのドラッグで囲んで選ぶ（Shift で追加）
```

- 選ぶ段: クリックした画像パーツから、**格子の付いたいちばん近い祖先のグループ**を選ぶ。どの祖先にも格子が無ければ、いちばん近いグループを選ぶ。グループに入っていない画像なら、その画像を選び、① に［グループを作る］を出す（今の節と同じ）。
- 「対象を変える」の一覧には、選んでいるグループの祖先（上から）・そのグループ・画像を含む一段下の子のグループを、字下げして並べ、格子があるものには「（格子あり）」を付ける。顔のグループに格子があり、目のグループに新しく格子を付けたいときは、ここで目のグループに切り替える。
- 編集する段: 今の制御点の操作のまま。右クリックで選ぶ段に戻る。何も無い所のクリックと Esc は D2 のとおり。対象の外の別のパーツを押したときの切り替えは D1 で決める（対象のグループの中のパーツを押しても切り替えない）。
- 案内の文:「① キャンバスでパーツをクリックして、画像を含むグループを選ぶ」「子に画像パーツが無い。画像をこのグループへ入れる」「② 格子が無い。ワープのパレットで［ワープを追加］を押す」「プレビュー中は編集できない。…」。どれもパレットとキャンバスの帯に同じ文を出す。

### 流れ線（ツールのパレット、カード99・CO）

- 線で曲げるツールのときだけ出す。登録（`curveGuide/index.ts`）で条件と ⓘ を足す。パネルの中身と、ツールの押したときの処理は変えない。
- 選ぶ段は枠が受け持つ。今の「画像パーツを選んでください」の知らせの代わりに、帯の案内とクリックでの選択になる。メッシュの無いパーツも選べ、パレットが「先にメッシュを自動生成してください」と出す（今の文のまま）。
- 編集する段で別のパーツを押しても切り替えない（クリックは線を描く操作に使う）。替えるときは右クリックで選ぶ段に戻る。
- パネルの下の［線で曲げるツールにする］は、ツールを使っている間しかパネルが出なくなるので出番が無くなる。消すかどうかは CO に任せる。

## 実装で決めたこと（2026-10-08）

- `target.pick` は、枠が押した点の画像パーツを調べて渡すのではなく、押した点（と変形の結果）を受け取り、ツールが選ぶパーツを決める形にした。枠がモデリングのパーツの当たり判定（ロックの扱いなど）を持たずに済む。
- 「対象を変える」の候補は、最後にクリックした画像からではなく、選んでいるグループの祖先と一段下の子から作る。選ぶ段の点線の囲みのためにマウスを動かすたびに `pick` を呼ぶので、`pick` に「最後にクリックしたもの」を覚えさせない（副作用を持たせない）ため。
- メッシュの何も無い所の2回目のクリックは、1回目のすぐ近くを素早く押すと、今までどおり頂点を足すダブルクリックとして扱う（画像の外なので「画像の外には頂点を追加できない」と出る）。少し離すか間を空けると、パーツの選択が外れる。
- 閉じた目の線は、なぞる前のツールを覚えて、なぞり終えたら・やめたらそこへ戻す（既定は選択・変形）。短すぎる線は今までどおり知らせて、なぞるツールのままにする。
- 流れ線のツールは、登録のときに `target` を足した写しを登録する（カード99 のツールの処理とファイルは変えない）。

進め方の案:

- 今回の実装では、パレットの中身・出す条件（`object`）・説明（`info`）を、置き場所（`area`・列の中の並び・たたみ）から切り離しておく。子ウィンドウ化は、列の代わりの入れ物（浮かべる枠・子の窓）を足すだけで済むようにする。
- 次に進めるなら、先に B2 が Tauri で成り立つかを試作する（窓を開く、ポータルで描く、キーと焦点、閉じたら列へ戻す、窓の位置と大きさを覚える）。その結果を見て、A・B のどちらにするか（両方にするか）を決める。
- I-064（パネルの高さ・幅の変更）と同じ「パレットの置き場所」の話なので、一緒に設計する。

検討するときに決めること:

- 浮かべる（A）と別の窓（B）のどちらが欲しいか。2台目のモニターを使うか。
- 子ウィンドウにできるのは共通パレットだけか、オブジェクトパレットもか（出たり消えたりする窓は目障りになりやすい）。
- 位置・大きさを覚える先（今のたたみの状態と同じ WebView の保存か、environment.json か）。
