# STEP4 の方針と候補（機能の追加・拡張）

状態: 実装計画あり（2026-10-07）。STEP3 は改善だけを行うので、[STEP3 の開発方針](step3-plan.md)にあった機能の追加・拡張をここへ移した。実装は [STEP4 の実装計画](step4/README.md)のカード73〜98 で行い、始めるのは STEP3 の受け入れ（カード72）の後。条件付きの候補（#5・#10・#12・#13・#14・#15）は、カード73 でユーザーと「行う」「見送り」を決める。#16（胸揺れ、I-061）は 2026-10-07 のユーザーの要望で足した（カード79・98）。#17（線で曲げる編集と重力に沿う髪、I-063）は 2026-10-08 に設計案を追加。実装の範囲・カード・完成条件は未確定。

見立ての欄は今の時点の意見で、決定ではない。大きさは S（数日）・M（1〜2週）・L（それ以上）の目安。

## 進め方

1. STEP3 の受け入れ（カード72）の後に、カード73 でこの一覧をユーザーと見直し、条件付きの候補を決める。
2. 実装は [STEP4 の実装計画](step4/README.md)のカードで行う。進め方の約束（同じ作業フォルダ・テストは相手が書く・契約は同時に1枚）は STEP3 と同じ。
