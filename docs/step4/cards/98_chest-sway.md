候補: #16（I-061）。完成条件: M9。型と規則はカード79 で決めてある（「胸揺れの物理」の項）。

## 目的

物理（揺れ）の種類に「胸」を足し、体の動きに合わせて胸を上下・左右に弾ませる。胸と体のつなぎ目（上端・脇）は動かさない。胸のパーツがあれば、かんたんセットアップで自動で付く。

## 前提

- 今の物理: 種類は髪・布・リボン・アクセサリ（`apps/desktop/src/modes/modeling/physics/presets.ts`）。揺れの自動のキー（`sway.ts`）は、ピボット中心の回転（transform）と、先端ほど大きい曲げ（vertices）。どちらも振り子の形。
- 物理演算（`packages/core/src/physics/engine.ts`）: 項目ごとに振り子を持ち、θ / range（−1..1）を出力パラメータに出す。方向が「左右と上下」（both）でも、出すのは左右だけ（上下の振り子は計算するが使っていない）。入力の一覧は両方の向きに共通。
- 評価: 同じメッシュへの vertices のバインディングが複数あれば、差分を足し合わせる（`packages/core/src/eval/evaluator.ts`）。
- メッシュ: 自動のメッシュは輪郭と内側の格子点（標準で 48px、なめらかで 28px ごと）を持つ（`packages/core/src/mesh/generator.ts`）。
- カード79 で足した型: `Physics['preset']` の 'chest'、`Physics.deform`、`Physics.verticalOutputParameterId`、`inputs[].axis`、標準パーツ 'chest'、標準パラメータ BustX・BustY、（範囲のモードを行うなら）`Physics.region`。
- 見本: カード74 の複雑な基準モデルの胸のレイヤー（自由パーツ）と、このカードで作る小さな見本。

## 設計（I-061 の検討の結果）

### 1. 変形の方式: 弾み（bounce）の頂点の差分

- **振り子型（今の sway.ts）は使わない。** パーツ全体をピボット中心に回すので、体とのつなぎ目（上端・脇）が体からずれ、隙間や重なりが出る。胸は「根元から垂れて振れる」のではなく、「つなぎ目を留めたまま中ほどから下が弾む」動き。
- **拡縮（transform の scale）も使わない。** 全体の大きさが変わり、つなぎ目が動く。
- **新しい変形器（ワープ）も作らない。** 胸を分けたパーツは、そのメッシュの頂点のキーで足りる。体に描いた胸（範囲のモード）も、体のメッシュの頂点で足りる。ワープはグループ化が要り、操作が増える。
- 頂点ごとの重み w（0..1）を決め、パラメータが ±1 のときの差分を「w × 振れ幅」にする。
  - **分けたパーツのモード**（既定）: 上下の位置 t =（y − 上端）/ 高さ、左右の端からの距離 s。fv = smoothstep(0.15, 0.85, t)（上端の 15% は 0 で留める）、fh = smoothstep(0, 0.2, s / 幅)（脇の付け根を留める）。w = fv × fh。
  - **範囲のモード**（条件付き。6 を参照）: 楕円の範囲で正規化した距離 r（中心は範囲の上から 60% の所）。w = (1 − r²)²（r ≥ 1 で 0。範囲の境界は必ず 0 なので、体の絵とのつなぎ目が出ない）。
- 振れ幅の初期値: 上下 = 高さの 6%、左右 = 幅の 4%（どちらも 16px まで）。値は物理の項目に持たず、キーの差分として残す（手で直せる）。
- キー: −1・0・1（source 'auto'）、generation 'linear'（円弧にしない。まっすぐ弾む）。上下（BustY）と左右（BustX）は別のバインディング。両方が動くときは差分の足し合わせで斜めに動く。
- **試作で比べる案**（最初に行い、ユーザーに選んでもらう）:
  - A: 平行移動の場（上の式）。
  - B: A に、体積を保つ伸び縮みを足す（下へ動くとき縦に伸び、横に少し縮む）。
  - 比較画像（上下 ±1・左右 ±1・斜め、物理のなし・あり）を、カード56 と同じ流儀の道具（開発用。`tools/dev/` に足す）で作る。既定は A。
- 作り直しの規則は揺れと同じ: キーがすべて auto・generated のバインディングだけ置き換え、手で直したものは残す（`isAutoSwayBinding` と同じ考え方）。

### 2. 物理の種類と値

- 種類「胸」（`preset: 'chest'`）。初期値は spring 120・damping 5・gravity 0・inertia 1.5・range 1.0。揺れ方 0.5（spring・damping は 0.8 倍）で、約 1.6Hz、1回体を振ると 2〜3 回弾んで 1 秒ほどで収まる見込み。実装で、体を1回振ったときの応答（θ の時系列）をエンジンの単体テストで確かめて決め、値と理由を記録に書く。
- 種類を選ぶと変形の方式も決まる（胸 → bounce、ほか → swing）。詳細で値を変えても（'custom'）方式は変えない（`Physics.deform` に持つ）。

### 3. 方向と出力

- 胸の既定の方向は「左右と上下」（both）。左右 → `outputParameterId`（BustX）、上下 → `verticalOutputParameterId`（BustY）。
- `verticalOutputParameterId` が無い（省略・null）ときは今と同じ（both でも左右だけ）。髪の揺れの値は変わらない。
- 「上下」だけを選んだときは、`outputParameterId` に上下（BustY）を出す（今の vertical と同じ）。

### 4. 入力

- 入力を向きごとに分ける（`inputs[].axis`。省略は両方で、今と同じ）。
- 胸を選んだときの既定: 左右 = BodyAngleX 0.5・BodyAngleZ 0.3・FaceAngleX 0.2、上下 = BodyAngleY 0.5・FaceAngleY 0.3・Breath 0.2。体の追従（bodyFollow）が顔の動きから体を動かすので、カメラだけでも弾む。
- 体の上下の位置（頭の位置の上下）があると、上下の弾みが自然になる。カード75 の実測で顔の位置が安定して取れ、カード79 でトラッキングの入力に足したときは、上下の既定にその入力を加える。

### 5. 標準パーツとかんたんセットアップ

- 標準パーツ「胸」（'chest'）: 任意。体の前・腕の後ろに描き、体の変形グループ（bodyRoot）の子にする。
- 標準パラメータ BustX（胸揺れ 左右）・BustY（胸揺れ 上下）: グループ「揺れもの」、−1..1。開いたときに足す標準パラメータには入れず、胸の揺れを付けたときだけ足す（胸の無いモデルに出さない）。
- かんたんセットアップ: 「胸」が割り当ててあれば、BustX・BustY・弾みのバインディング・物理の項目（chest・bounce・both・既定の入力）を作る（1回の Undo）。無ければ何もしない（結果は今と同じ）。
- [パーツの画像生成のプロンプト](../../part-image-prompts.md)の「体」に「胸」を足す。胸が弾んで動いた所に隙間が出ないよう、体（torso）は胸の下も塗っておくと書く。

### 6. 範囲のモード（条件付き。カード73 で決める）

- 胸が体に描いてあり、分けたレイヤーが無いときのモード。体のパーツを選び、キャンバスに楕円の範囲を置いて「胸」の揺れを付ける。範囲は `Physics.region`（中心と半径。キャンバス座標）に保存する。
- 範囲の中の頂点が少ない（目安 9 個未満）ときは、メッシュを「なめらか」で作り直すよう案内する（作り直しはカード61 の確認と同じく、ずれの量を出す）。
- 胸が分けたレイヤーで描かれているモデルだけなら、このモードは見送る。
