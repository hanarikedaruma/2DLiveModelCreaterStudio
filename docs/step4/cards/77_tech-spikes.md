候補: #10・#13・#14。カード73 で、カード93（MIDI）・94（仮想カメラ）・95（腕のトラッキング）のどれかを「行う」と決めたときだけ、その分を行う。どれも行わないなら「見送り」。

## 目的

行うと決めた候補が、このアプリの制約（外へ通信しない、Windows 10 / 11、WebView2、描画の性能）の中で作れるかを、小さな試作で確かめる。

## 確かめること

| 候補                         | 確かめること                                                                                                                                   |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| MIDI（カード93）             | WebView2 で Web MIDI が使えるか（許可の出し方、Tauri 側で要る設定）、機器の一覧と抜き差し、遅延、外へ通信しないこと                            |
| 仮想カメラ（カード94）       | Windows 11 の仮想カメラの仕組みを Rust から使えるか、Windows 10 の扱い、既存の D3D11 の描画（Spout2 の経路）からフレームを渡せるか、透過の扱い |
| 腕のトラッキング（カード95） | MediaPipe の姿勢の推定（モデルを同梱）を顔の推定と同時に動かしたときの fps と遅延（この PC）、ふつうのカメラの距離で上半身が写るか             |
