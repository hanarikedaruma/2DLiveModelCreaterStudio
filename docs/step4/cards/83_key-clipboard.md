## 目的

キーをコピーし、別の値・別のパラメータ・別のパーツへ貼り付けられるようにする。

## 前提

- カード78 の `packages/core/src/keys/`（クリップボードの形・写し方・頂点数の違う形への写し）。
- パラメータパネル: `apps/desktop/src/modes/modeling/parameters/`（STEP3 のカード63 で、印のメニューに「消す」「動かす」を足してある）。キーの編集: `apps/desktop/src/services/keyEditor/`。
- 文字入力中のショートカットの判定: I-014 の判定（`apps/desktop/src/shell/keys.ts`）。

## 作るもの・直すもの

1. 選んだパーツ（複数可）の、今のパラメータの値のキーをコピーする（Ctrl+C、印のメニュー）。
2. 貼る先: 同じパーツの別の値、別のパラメータ、別のパーツ（Ctrl+V、メニュー）。頂点数の違うメッシュ・格子の違うワープへはカード78 の写し方。
3. 貼る先に手で直したキー・ロックしたキーがあれば、上書きするか確かめる。
4. 文字・数値の入力中は、入力欄のコピー・貼り付けを使う。1回の貼り付けは1回の Undo。
