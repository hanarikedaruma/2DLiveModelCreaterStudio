# 線で曲げる編集と、重力に沿って垂れる髪の設計案

2026-10-08 CO。I-063、STEP4 候補 #17。ユーザーの「これを実装して」という指示で、[カード99](cards/99_curve-guide.md)・契約CC-011として先行実装。一本の流れ線、中間・毛先の編集、影響幅、根元の追従、連続する重力補正、手動キーへの記録、保存/Undoを製品へ追加。実画面の検証はカード99に記録する。慣性・肩との接触は[具体設計](hair-dynamics-design.md)を追加したが、製品への実装は未着手。3Dねじれも後続の範囲。STEP3の受け入れや他のSTEP4カードの着手とは分ける。

## 解決したいこと

頭を傾けると、長い髪が頭と同じ角度で一直線に傾く。頂点を個別に動かして下へ垂れる形へ直そうとすると、輪郭ががたがたになる。

ユーザーの補足: 「要は、髪の毛が重力の影響で斜めにはならないようにしたいということ」。したがって、毛先の正面時の X/Y を固定することを基本にしない。**根元は頭について動き、髪の下の部分は重力の下向きへ近づき、毛先の位置はその結果として決まる**。カール・毛束のふくらみも残す。

このため、次の2つを組み合わせることを推奨する。

1. **線で曲げる**: 髪の中心に一本の「流れ線」を引き、その線の少数の点で周囲のメッシュを滑らかに編集する。
2. **重力に沿わせる**: 頭の現在の姿勢に応じて流れ線を計算する。根元側は頭の向きに追従し、下側ほど頭の傾きの影響を弱める。

単一キーの修正だけでは、キーの間や別の姿勢で常に下へ垂れる保証にならない。重力への追従までを実現する最終案は、再生中も流れ線を評価する方式とする。

## 操作の案

最初は髪の画像パーツ1枚を対象にする。メッシュの頂点を選ぶ操作は不要。

1. 髪を選び、「線で曲げる」を選ぶ。
2. 根元から毛先へ一本なぞる。手ぶれを取り除き、根元・中間・毛先の3点程度の線にする。根元と毛先をクリックして始める方法も用意する。
3. 「重力に沿わせる」を有効にすると、頭を傾けても下側が垂れる形になる。
4. 中間の点を動かしてふくらみを調整する。「根元の固さ」で、頭について回る区間の長さを調整する。

初期の表示は「根元」「中間」「毛先」と「根元の固さ」「影響幅」だけにする。曲率の数値や Bézier の接線ハンドルは最初から出さない。必要な場合だけ中間点を増やせる。

根元の点だけを留めると付け根が回転して浮くため、**短い根元の区間と、その向き**を頭に追従させる。端の点を動かしたい場合は「付け根の位置を変更」の明示操作にする。

線の周辺に薄い影響範囲を表示し、外側へ滑らかに弱める。根元の区間と対象パーツも表示する。同じ画像に別の毛束がある場合は、距離だけでなくメッシュの連結と線の所属区間で対象を絞る。

汎用の「線で曲げる」には、現在のキーへ形を記録するモードも用意する。こちらは髪に限らず、布・リボンなどを1〜数点で整える用途。

## 重力の動き

| 部位           | 基本の動き                                                 |
| -------------- | ---------------------------------------------------------- |
| 根元の短い区間 | 頭に追従。付け根の位置・接線の向きを保つ                   |
| 中間           | 頭の向きから下向きへ、滑らかに移る。編集したふくらみを残す |
| 毛先側         | 重力方向へ近づく。正面時の位置には固定しない               |
| カール         | 毛束の基準の曲がりを残し、一直線には伸ばさない             |

重力は出力画面の下向きと定義し、モデル座標へ変換して使う。キャンバスのパン・ズームは重力の方向を変えない。シーン配置の回転がある場合は、その回転も変換に含める。反転・非一様な拡縮の扱いを契約とテストで固定する。

初期の試作では、線を等間隔の短い区間へ分け、各区間の長さを保ちながら向きを変える。根元では頭の回転をそのまま使い、下へ進むほど回転の追従率を滑らかに下げる。正面時の線の曲がりを基準として残す。これは自然な垂れ方を作る近似で、毛髪の厳密な力学計算ではない。

この近似と、曲げの固さ・長さの制約を持つ方式を、長い直毛・カール・太い毛束の見本で比較する。現在の全体回転を逆向きに足すだけの方式は、付け根まで動かしてしまうので採用しない。

動きを止めたときの垂れ方を先に作る。頭を動かした後の遅れ・揺れ・減衰は、その垂れ方を基準にした次の段階とする。慣性・肩との接触の計算と操作は[hair-dynamics-design.md](hair-dynamics-design.md)へ分ける。99の範囲には加えない。3Dのねじれは今回の後続設計にも含めない。

流れ線は形の編集だけにも使う。**線を指定しただけで慣性の揺れを追加しない。** 後続の［流れ線をしならせる］は流れ線ごとの別設定で、新規・既存とも初期OFF。選んだ対象で明示的にONにした場合だけ揺らす。重力の静的な補正だけを使い、遅れや余韻を付けずに垂らすこともできる。既存の［揺らす］はピボット中心の回転と先端側の曲げのキーを作る方式。根元を付けたまま垂れた線をしならせる新方式と、名称・説明を区別する。

## 線からメッシュへ移す方法

線だけ滑らかでも、頂点への写し方が不適切だと輪郭・幅・三角形が崩れる。ここを独立した試作の対象にする。

- 編集開始時に、各頂点について基準線の長さ方向の位置と、線から横への距離を記録する。ドラッグの途中で対応を取り直さない。
- 変形後の線の向きに合わせて横方向も回す。頂点へ同じ移動量を足すだけの方式より、毛束の幅を保ちやすい。
- 線の影響範囲の外では移動量を0にし、境界では移動量とその変化が滑らかにつながる重みを使う。
- 根元の区間は別の追従制約として扱う。輪郭を平均して平らにする処理は使わず、変位の場または局所的な形の維持を対象にする。
- 自己交差する線・近接する毛束では最近点だけの対応が飛ぶため、線の区間の所属とメッシュの連結で対応を保つ。

| 候補                                       | 利点                                         | 比較で確認すること                                     |
| ------------------------------------------ | -------------------------------------------- | ------------------------------------------------------ |
| 曲線の位置・向きによる変形＋滑らかな影響幅 | 毛束の流れを直接扱える。対応を事前計算できる | 強く曲げたときの幅、根元と影響範囲の境界、近接する毛束 |
| rigid / similarity MLS による線・点の操作  | 少数のハンドルから周辺の変形を作れる         | 局所的な影響範囲を加えた際の連続性、長さ、反転         |
| ARAP など局所的な形を保つ制約付き変形      | 大きく曲げる場合の伸び・つぶれを抑える候補   | 速度、収束、根元の保持、粗いメッシュ、失敗時の復帰     |

最初は曲線の位置・向きによる方式を試し、必要なら局所的な形を保つ計算を加える。線を使う MLS や滑らかな重みは既存研究にもあるが、それだけでこのアプリの三角形の反転や複雑な親ワープの問題が解決するとは扱わない。

三角形の面積が0に近づく・新しく反転する場合は、最後の有効な形に戻す。変形量を弱めて有効な範囲まで戻す方法も比較する。親の反転を含む開始時の向きと比較し、負の拡縮を一律に不正として扱わない。頂点の不足で線の曲がりを表せない場合はその理由を表示する。キーを失う自動メッシュ再生成は行わない。

**手動でキーへ記録する場合**: 最終頂点を局所座標へ逆変換し、既存のKeyEditorで現在のキーへ記録する。逆変換やキー追加が失敗した場合に一部だけ書き換えず、取消と1回のUndoを維持する。記録した線の常時変形は解除して二重に適用しない。

**重力へ常時追従する場合**: 通常のキー・親の変形を評価した線を基準に、根元の角度差を下側ほど取り除く。既存の頂点キー・カールの形を入力として保ち、最終線をメッシュへ写す。質点に重力を積分する計算やSceneの重力設定は現在の実装には無い。モデルのキャンバス座標で静的に補正し、毎フレーム保存しない。上の重力座標の説明は当初の設計方針として読み、シーン回転の追加時は別の契約を要する。

現在は子を持たない髪の画像パーツ1枚に限定している。子や別画像のハイライトを同じ線へ追従させる対応は未実装。重力を有効にする対象では既存のHair物理を確認付きで解除し、他の対象の物理は維持する。新しい流れ線を基準にする慣性と肩の接触の拡張は[後続設計](hair-dynamics-design.md)に記す。

## 保存・キー・編集の保護

流れ線を一度使ったら消える道具にはしない。保存して開き直した後も、同じ少数の点で編集し直せることを含める。

カード99/CC-011で `Model.curveGuides` に、線と対象パーツ/メッシュのID、基準の3点と編集した3点、影響幅、根元の区間、重力/有効設定、メッシュの幾何の指紋を保存した。`Project.schemaVersion` は4で、3→4は空の流れ線へ移行する。メッシュ再生成や基準頂点変更で指紋が変わると失効し、描き直しを案内する。対象不在の線は読込時に修復する。

- 手動編集では現在のキーだけを変更する。プレビュー中に基準のメッシュを誤って変更しない。
- 他の manual / locked キーを一括生成で上書きしない。キーの追加と線の編集を含め、取消と1回の Undo / Redo にする。
- 手動の線を既存の頂点キーへ記録した場合、その線をさらに実行時の変形として重ねない。
- 頂点を個別編集した後は、記録した線との対応が古くなったことを表示し、古い線の再適用で個別編集を消さない。
- 削除・複製・左右反転・PSD 再読み込み・メッシュ再生成で線をどう扱うかを定義する。特に対応の取れない新しいメッシュへ無言で適用しない。
- 重力方式から通常のキーへ変換する場合は「角度ごとの形を記録」を別操作にする。キーの間で下向きが保てるか評価し、必要な空きキーだけを追加する。変換後は実行時の重力補正を解除する。

## 試作と実装を分ける案

| 段階       | 作るもの                                                                  | 判断するもの                                           |
| ---------- | ------------------------------------------------------------------------- | ------------------------------------------------------ |
| 試作       | 長い直毛・カール・太い毛束で、3点の線と根元の区間、角度ごとの垂れ方を比較 | がたつき、幅と長さ、根元、反転、計算時間               |
| 契約       | 線の保存、評価順、重力の座標、失効/再対応、既存物理との切り替え           | 既存キー・描画・選択・出力で同じ形になること           |
| 手動編集   | 一本なぞる→少数点で曲げる→現在のキーへ記録                                | 頂点を1点ずつ触らずに形を作れること                    |
| 重力追従   | 保存した線を姿勢に応じて毎フレーム評価                                    | 根元が頭に追従し、下側が垂れ、角度の間でも連続すること |
| 揺れの統合 | 垂れた形を基準に、遅れ・揺れ・減衰を加える                                | 静止時の姿勢へ戻ること。古い物理との二重適用が無いこと |

STEP4 の #3 / カード76・82・89 の関節と、影響の重みや線の保存を共用できる可能性はある。ただし腕の関節の保持と、髪の重力への追従は別の完成条件を持つ。#12 / カード92 の「曲線エディタ」は時間の補間の曲線であり、この空間の流れ線とは区別する。上の手動編集・静的な重力追従はユーザーの指示によりカード99で先行実装した。慣性・肩との接触の正式カードと契約の直列順は、後続の実装計画へ組み込むときに確定する。

## 検証条件の案

以下の数値は**試作で評価する目標**で、実測結果・確定した製品の完成条件ではない。

| 確認         | 条件の案                                                                                            |
| ------------ | --------------------------------------------------------------------------------------------------- |
| 根元         | 傾き −30〜+30° で、短い付け根の区間が頭の変形に1px以内で追従。接線も連続する                        |
| 垂れる方向   | 直毛の見本では先端側の接線が下向きから5°以内。毛先の X/Y の固定を要求しない                         |
| 幅と長さ     | 上記の見本で長さ・幅の変化を10%以内に抑える。カールは別の輪郭比較を行う                             |
| 滑らかさ     | 線の制御点、根元の区間、影響範囲の境界で急な折れ・輪郭の段差が無い                                  |
| 連続姿勢     | キーのある角度だけでなく、1°刻みで往復し、線や頂点が飛ばない                                        |
| 編集しない点 | 対象外のパーツと影響範囲の外の頂点は変えない                                                        |
| 恒等性       | 同じ線への操作は変形なし。手動の取消・保存/再読込の頂点差は1e−6以内                                 |
| 変換         | 自身/親の回転、反転、非一様な拡縮、2段のワープ、I-054 の既存例で検証                                |
| 破綻         | 新しい反転、面積0、逆変換失敗、NaN では最後の有効な状態を保持                                       |
| 履歴・保護   | 1回の Undo / Redo、Esc、locked、manual の他キー、プレビュー中の操作、プロジェクト切り替え           |
| 保存の対応   | 線の再編集、複製、左右反転、PSD 再読み込み、メッシュ変更時の失効を往復確認                          |
| 評価器の一致 | 編集表示・当たり判定・スタジオ・出力が同じ頂点になる。物理を二重適用しない                          |
| 速度         | 操作の更新は33ms以内を仮目標として測る。毎フレームの重力計算は既存モデル全体の60fpsの予算内に収める |
| 操作性       | 初見の人が、流れ線を一本引いて中間点を動かすだけで、頭が傾いても垂れる髪を作れる                    |

複雑な親ワープ、肩との接触、複数の重ねた絵、粗すぎるメッシュでどこまで成立するかは、試作と実際のモデルの目視で決める。

2026-10-08 の確認: 会話の概念図では、頭の傾き・根元の追従区間・中間の曲がりを動かし、根元が頭について動き、毛先側が下向きになる動きを確認。Edge の幅736px/320px、マウスのドラッグ、左右キー、設定の復元、値の両端での表示に実行時エラーは無かった。これは描き方を説明する概念図の確認で、上の製品の検証条件を通した結果ではない。

## 参考

- [Image Deformation Using Moving Least Squares — Schaefer ほか、2006](https://people.engr.tamu.edu/schaefer/research/mls.pdf): 点・線分をハンドルとする変形、rigid / similarity の比較。線による編集が成立する根拠。重力方式の根拠ではない。
- [libigl tutorial — Biharmonic deformation / ARAP](https://libigl.github.io/tutorial/): 基準の形を保つための変位の扱いと、大きな回転での局所的な形の維持の比較。
- [Bounded Biharmonic Weights — Jacobson ほか、2011](https://igl.ethz.ch/projects/bbw/): 滑らかで局所的な影響の重みを事前計算する候補。今回の独自の影響幅と反転防止の保証には代えない。
