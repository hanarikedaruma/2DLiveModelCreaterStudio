# 胸揺れの重力と慣性の座標（カード98・I-061）

状態: 修正設計・製品実装は未着手（2026-10-08・CO）。ユーザーの「体を斜めにしても揺れる方向が体とまっすぐではおかしい」という指摘を受けた修正。[設計再確認](chest-sway-design-review.md)・[カード98](cards/98_chest-sway.md)・79の胸揺れ部分に対し、この文書の重力・入力・キーの座標・評価順を優先する。

## 動作の条件

- 体が傾いても、重力はモデルのキャンバスの下向き。体や胸のローカルの上下軸と一緒に回さない。画面のパン・ズーム・出力先の拡大率は力に含めない。
- 上端・脇の固定点は体の姿勢に付いていく。自由な部分は重力、体の動きに遅れる慣性、ばね、減衰の合成で変形する。慣性には横向きの成分もあり、変位や揺れの軌跡すべてを垂直に制限する意味ではない。
- 傾けたまま止まっても、その姿勢での重力との釣り合いが残る。動作中だけ揺れて、止まると体の上下軸へ戻る設計にしない。
- 正面の基準の絵は、既に重力で垂れた形として扱う。基準姿勢で追加の垂れを二重に加えず、傾いたときの重力方向の変化を消さない。
- この座標の規則は、分けた胸にも、将来の範囲指定の胸にも共通。範囲指定の実装の採否は従来の条件付き範囲のまま。

## 現行エンジンへ係数を足すだけでは足りない

`physics/engine.ts` の `gravity` は振り子の角度に対する `-gravity * sin(theta)`。胸へ常に下向きの加速度を与える式ではない。また、現行のverticesキーは自身と親の変換・ワープを掛ける前に足されるため、ローカルの上下キーは体と一緒に回る。

単純な回転だけなら、モデル座標の変位を行列の線形部分の逆でローカルへ戻してもよい。しかし、角度だけの逆回転では非一様な拡縮・反転・複数の親を扱えず、1つの行列では非線形ワープを扱えない。胸の方式Aは次の評価順にする。

1. 既存のパーツ内の頂点差分、胸自身と祖先の変換、祖先のワープを適用し、胸が体に付いた基礎の姿勢を作る。
2. 胸の重み付き差分を**モデル座標**で足す。方式Aでは `完成頂点[i] = 基礎頂点[i] + w[i] * q`。qのX/Yは体と一緒に回さない。
3. 同じパーツの流れ線の補正、流れ揺れ、肩との接触などの完成形の評価へ進む。髪へ渡す肩・体の形は胸の差分を含める。

この順なら固定点は `w=0` のため厳密に基礎の姿勢のままで、自由点への下向きの差分は、体の回転・非一様拡縮・反転・ワープによって斜めにならない。体自身の独自の頂点変形を別パーツの胸が継承できない問題は別に残るため、前の設計再確認の保護を維持する。

## 保存するキーと契約

胸も頂点の差分と既存のキー補間を使う。新しい操作用ワープは作らない。ただし、従来のキーと足す位置が異なるため、次を胸の先行契約に含める（以下は未実装の型案）。

- `Binding.vertexSpace?: 'part' | 'model'`。verticesだけに有効。省略・partは従来どおり変換前の差分。胸の自動キーはmodelにし、変換・祖先のワープ後に足すベクトルを保存する。transform/warpPointsでmodelを指定したら検証で拒否する。
- `TargetDeltas.modelVertices?: Record<meshId, Float32Array>`。評価器はpartの差分とmodelの差分を別々に合成する。変形器は上記の順で適用し、同じ差分を2回足さない。既存のverticesの意味を変更しない。
- 胸用の保存項目 `Physics.bounce?: { gravityStrength: number; referenceCenter: Vec2; referenceBasis: [Vec2, Vec2]; amplitudes: Vec2 }`。gravityStrengthは0..1、既定候補0.3。referenceCenterは対象メッシュの基準座標、referenceBasisは基準姿勢でのローカル→モデル座標の2つの基底ベクトル、amplitudesはモデル座標での左右・上下の正の振れ幅。固定範囲・メッシュ対応・自動キーの所有の記録も一緒に保存する。
- referenceBasisは有限で逆変換可能な行列、胸のspringは正、dampingは非負で検証する。deform=bounceにはbounceの保存項目を必須とする。新規設定時はパラメータの既定値の基準姿勢で生成し、トラッキング・お試し・編集中の傾きを勝手に基準にしない。単なる再生・再読込・体の傾き変更で取り直さない。無効な基準は胸の自動適用を止め、理由を表示する。5→6の移行で旧モデルへ胸設定を作らない。
- BustX/BustYは、モデル座標の左右・上下の変位をamplitudesで割った出力。正のXはキャンバス右、正のYは下。方向「上下だけ」はモデル座標のYだけを使う。胸の既定はbothとし、体の傾きに応じた両成分を表せるようにする。

−1・0・1のmodelの自動キーは、左右なら `(w * amplitudeX, 0)`、上下なら `(0, w * amplitudeY)` の場を表す。表示・編集・保存・再生で同じ意味にする。手で直した胸のキーもvertexSpaceを維持し、既存のmanual/lockedの保護を継続する。編集操作は表示中の基礎の姿勢からのモデル座標の差分を保存し、パーツ座標へ勝手に戻さない。胸の固定頂点への差分は編集時も0に保ち、読み込みでこの条件を満たさないキーがあれば上書きせず自動適用を止めて理由を表示する。

左右反転では頂点・固定範囲の対応を反転するが、自動のmodelキーのベクトルを体のローカル座標として反転しない。専用出力を作り、正のXが右、Yが下となるよう再生成する。manual/lockedキーを再生成できない場合は黙って符号を変えず、既存の保護に従う。従来の軸揺れとpartのキーの反転規則は維持する。

## 体の動きと釣り合い

胸用には、モデル座標で2次元の相対変位qとその速度vを保持するセッションを作る。体の回転だけを理由にq/vを回転させない。体が斜めでも、実際の横への加速には横への遅れを出す。

基礎の姿勢で、保存したreferenceCenterが移った位置をp(t)、その近傍のローカル→モデル座標の線形変換をJ(t)、保存した基準をJ0とする。p(t)の位置・速度・加速度をモデル座標で追跡し、体の回転・移動・呼吸による実際の動きを入力にする。回転には中心の移動を通じて接線・求心の加速度も含まれる。パラメータのBodyAngleX/Y/Zや顔の動きを、そのまま空間の加速度として扱わない。

方式Aの最初のばねは2方向で共通の正の係数k、減衰はcとし、単位質量の式を次にする。時間は秒、座標はモデルのpx。strengthによる調整後の係数を使う。

```text
sag = gravityStrength * amplitudes.y
g = (0, k * sag)                         // px/s²。モデルの下向き
r0 = inverse(J0) * (0, sag)              // 基準の絵へ二重に垂れを足さない校正
q'' = -k * (q + J(t) * r0) - c * q' + g - inertia * p''(t)
qEquilibrium(t) = g / k - J(t) * r0      // 体が静止したときの釣り合い
```

`r0` はばねの無荷重の基準を求める校正であり、毎フレーム重力をゼロにする処理ではない。基準姿勢では `qEquilibrium=0`、体を傾けると一般には0ではなくなる。既に描かれた垂れを体と一緒に回した成分との差なので、釣り合いの補正変位には左右成分もあり、下向きの重力だけの変位と混同しない。gravityStrength=0なら校正も0になり、慣性・ばね・減衰だけになる。

J(t)は取付けの向きと大きさを扱うための局所の変換であり、重力ベクトルを回すために使わない。ワープでは中心近傍の変換を取り、完成したメッシュへ加えるqは引き続きモデル座標に置く。基準を保存しているため、途中の傾いた姿勢で開始・再読込しても、その姿勢のqEquilibriumで初期化できる。毎回q=0に戻して静的な重力を消さない。

基準姿勢やメッシュを変えた場合は、基準を取り直す操作と通常の再生の初期化を分け、Undo・保存の対象にする。ばねや重力の強さの変更でr0を計算し直す場合も保存したJ0を使い、現在の傾きを基準に置き換えない。実行中の退化した形や非有限値は胸の差分を止めて状態を同期し、理由を表示する。

既定の胸では、体の実際の動きからの慣性を使い、同じ動きをBodyAngle・FaceAngle・Breathの差分で再度加算しない。顔から体への追従が体を動かしたときはp(t)に現れる。顔だけが動いて体が動かないときは、それだけでは胸を揺らさない。従来のswingのパラメータ入力・axis省略の互換は保ち、胸への追加の演出的な入力は明示的に設定した場合だけ扱う。

## 1フレームの評価と安全性

現行の `FrameContext.mixedSoFar` と振り子だけでは、最終的な体の姿勢を受け取れない。胸の幾何と状態を扱うフレームの契約を先行作業へ追加する。

1. 既存の入力層・軸揺れを合成し、胸揺れの所有するmodelキー（手編集後も含む）だけを除いて体と胸の基礎の姿勢を評価する。体や髪のキーを中立化しない。参照用の評価では物理や流れ揺れの時間を進めない。
2. 基礎の姿勢のp(t)/J(t)、now/dt、frameId、physicsActiveで胸のセッションを1回進める。固定刻みは1/120秒、通常の上限8回。姿勢の位置の差分から得る速度・加速度を平滑化し、最初のサンプル・長い停止・シークの飛びを加速度として使わない。
3. 胸の2出力をphysicsの層へ追加し、既存の層の優先順位・重みで再合成する。完成した差分を上記の順で適用し、流れ揺れの評価と肩の形を確定する。プレビューと全出力は同じ完成形を共有する。同じframeIdの再表示では再積分しない。

胸の出力から取付け元・祖先の姿勢へ戻る循環は作らない。自動設定時の利用判定でこの依存が見つかったら自動適用を止める。モデリングの静止プレビューはqEquilibriumを評価し、時間を進めず傾いた静止状態を確認できる。パラメータキーを編集する操作では、設定中のBustX/Yを物理で上書きしない。お試し・スタジオ・アニメーションは専用の動的セッションを持ち、切替・シーク・ループ・停止・プロジェクト変更で初期化する。

生成時だけでなく、現在の基礎の姿勢へ左右・上下の差分を合成した三角形でも反転・潰れを防ぐ。方式Aの同じ重みなら、モデル座標の差分でも三角形の符号付き面積はqのX/Yに対して一次なので、同時出力の4隅で検査できる。回転・拡縮・ワープ後の基礎の姿勢で再確認し、必要ならモデル座標の振れ幅と外へ向かう速度を制限する。固定点は制限の有無にかかわらず0。手で直した異なる場のキーには、この一次性を無条件に当てはめない。
