# STEP4 の実装計画（カード）

[STEP4 の方針と候補](../step4-candidates.md)を、カードに分けた実装計画。STEP4 は**機能の追加・拡張**を行う。始めるのは STEP3 の受け入れ（カード72）の後。担当は STEP3 と同じく **CL**（Claude Code）と **CO**（Codex）。

2026-10-08: ユーザーが I-063 / 候補 #17 の[設計案](curve-guide-design.md)を実装するよう指示したため、[カード99](cards/99_curve-guide.md)として先行着手（CO）。このカードだけは72/73の待ちを解除し、契約CC-011も99で直列に行う。STEP3は未受け入れのまま、他のカードの開始条件は変えない。CLの残作業の引き継ぎに従い、COが実装と追加テストを行う。カード92の時間の補間の曲線とは別の機能。

## 使い方

- 進め方の約束は [STEP3 の README](../step3/README.md) と同じ。特に次の節をそのまま使う: 「同じ作業フォルダで2人が進めるときの約束」「テストの分担」「使う確認の仕組み」「どのカードにも共通の完了条件」「状態」「計画を直すとき」。
- 1枚のカードが1つの作業単位。カードのファイル（[cards/](cards/)）だけを読めば作業できるように書いてある。番号は STEP3（55〜72）の続き。
- **テストは相手が書く。** CL のカードのテストは CO が、CO のカードのテストは CL が書く（一覧の「テスト」の欄と、各カードの「テスト（担当: …）」の節）。
- **条件付きのカード**（77・81・91〜96）は、カード73 でユーザーと「行う」「見送り」を決める。見送りのカードは状態を「見送り（理由）」にし、依存の表から外す。
- 新しい開発環境・リモートは作らない。新しい機能の依存（zip・姿勢の推定のモデルなど）も、外へ通信しないものだけを同梱する。
