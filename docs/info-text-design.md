### ボタンが実際にしていること（`modes/modeling/parameters/generate.ts`、`packages/core/src/generate/`）

- キーには「代表のキー」（●。手で作った・自動で作った・ロックした）と「中間のキー」（○。生成したもの）がある。中間のキーを手で直すと、代表のキーになる。
- **［間を生成］**: 編集中のパラメータの、隣り合う代表のキーの間に、中間のキーを等間隔に作る（顔の向きなど幅の広いパラメータは 10 ごと、0〜1 のものは 0.25 ごと）。ロックしていない中間のキーは作り直す。方式はバインディングごとの生成方式のまま。パーツを選んでいれば、そのパーツ（と子）だけに掛かる。
- **［すべて再補間］**: ロックしていない中間のキーを消し、生成方式で作り直す。範囲の全体に掛けたときの結果は［間を生成］と同じになる。印の Shift+ドラッグで範囲を選ぶと、その範囲だけを作り直せる（選択範囲だけ再補間）。
- **［奥行きで作り直す］**（顔の向きのときだけ）: 頭の中の画像パーツを、奥行き（前髪は手前、後ろ髪は奥）に合わせて、左右・上下の向きで ±30 のキーを作り直す。ロックしていないキーは手で直したものも作り直される。
- **生成方式**（詳細のときだけ）: 中間のキーの作り方。
  - 線形: 両端のキーをまっすぐ混ぜる。ふつうはこれ。
  - 回転: 頂点・制御点を、回転の中心のまわりの円弧に沿って動かす。腕や髪を振るような動きで、途中で形が縮まない。
  - なめらか: キーの近くでゆっくり、真ん中で速く変わる。まばたき・口の開け閉め向き。
  - 曲面: 顔の向きのワープを、球の面に沿って作り直す（顔の向きのときだけ）。手で直したキーも、ロックしていなければ作り直される。

線形のときは、中間のキーを作っても見た目は変わらない（キーの間は、もともとまっすぐ補間される）。作る意味は「途中の値のキーを直せるようにする」こと。回転・なめらか・曲面では、中間のキーで途中の動きが変わる。

## 考え方

### 外部のテキスト

ⓘ の文を1つのテキストファイルにまとめ、そこから読む（D1・D2）。

- 置き場所: `apps/desktop/src/help/info.md`（日本語）。ビルドのときにアプリに入れる。
- 書き方（そのまま読めるマークダウン）:

```markdown
## parameters.generateBetween 間を生成

編集中のパラメータの、代表のキー（●）の間に中間のキー（○）を作る。

- 両端のキー（例: −30 と +30）を作ったあとに押す
- 線形なら見た目は変わらない。途中の値（例: +10）の形を直したいときに、そのキーが用意される
```

- `## <id> <見出し>` で1つの説明。最初の段落が目的、`-` の行が使いどころ、`1.` の行が手順（今の ⓘ の手順）。
- id は、パネルなら登録の id（`mesh` など）、パネルの中の項目なら `パネルid.項目`。
- 読み方: ビルドのときに文字列として読み、起動のときに id ごとの表にする。登録の `PanelDef.info` は id を指すだけにする（文は持たない）。
- テストで、使っている id がすべてファイルにあること、ファイルにある id がどこかで使われていることを確かめる（書き間違い・消し忘れを防ぐ）。

### パネルの中の ⓘ

パネルの見出しの ⓘ と同じ見た目の小さい ⓘ を、ボタン・選ぶ欄の横に置く（D3）。押すと、そのすぐ下に説明を開く（もう一度押すか Esc で閉じる）。

```
┌ パラメータ ───────────────────────────── ⓘ ┐
│ キーを編集中: 顔 左右                          │
│ [値をすべて戻す] [間を生成]ⓘ [すべて再補間]ⓘ   │
│ ┌──────────────────────────────────┐ │
│ │ 間を生成: 代表のキー（●）の間に…        │ │ ← ⓘ を押すと開く
│ └──────────────────────────────────┘ │
│ 生成方式 [線形 ▾] ⓘ                           │
```
