# キーの形を透かして見比べる（設計）

2026-10-11 CL。ユーザーの要望（課題は I-070）。最初の案（決めてほしいこと D1〜D9）に、ユーザーが「複雑にしない」と答えたので、それに合わせて作った。

## 解決したいこと

ユーザーの言葉:

> あと指定したキーの状態を薄く透かし表示したい。キー作成時に何度も前のキーを選択して、高さがどれくらい違うだの回転がどれくらい違うなどを記憶頼りに操作することになるのが嫌。

## 今の作り（コードで確かめたこと）

| 項目                 | 今の作り                                                                                                                                                                                  | 問題                                         |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| キャンバスの描画     | 今のパラメータの値（`editorParamValues`）の形を1つだけ WebGL で描き、その上の2Dのキャンバスに重ね描き（枠・ハンドル・メッシュ・案内）を描く（`shell/canvas/CanvasHost.tsx` の `drawNow`） | ほかのキーの形は描けない                     |
| キーの印             | 印を押すとその値へ移る（カード63。`modes/modeling/parameters/KeySlider.tsx`）                                                                                                             | 見比べるには、キーへ移り直して覚えるしかない |
| Transform のパレット | 選んだパーツの基準の形の値。パラメータの編集中も基準の形の値を読み取り専用で出す                                                                                                          | 今のキーの形の数値が分からない               |

## 決めたこと（2026-10-11 ユーザー）

ユーザーの答え:

> 複雑にしない方針で。数値は、今のものだけでいい。現在の状態を透かしにするボタンみたいなのがあって、それを押すと透かしになる。もう一回押すと解除される。

- **［透かし］ボタン**: キャンバスの上のツールの並びの右（倍率と［全体を表示］の左）に置く。押すと、今キャンバスに見えている形を止めて、青く薄く今の絵の上に重ねる。もう一度押すと消える。押している間はボタンが押された見た目になる。
- **透かしの形**: 押したときの形のまま変わらない。値を変えても、キーを直しても、ツールを変えても残る。表示（拡大・移動）には合わせる。
- **数値**: Transform のパレットは、パラメータの編集中と、値がデフォルト値でない間も、今の形の値（基準 + キーの差分。位置・回転・拡縮・不透明度）を読み取り専用で出す。案内は「パラメータ編集中は画面上で操作（数値は今の形）」にした。透かしの数値・差は出さない。
- **消えるとき**: もう一度押したとき、別のプロジェクトを開いた・新規に作ったとき、モデリング以外のモードへ切り替えたとき（キャンバスを閉じるので）。保存しない。

最初の案から作らなかったもの: キーの印の右クリックの「このキーを透かす」、パラメータのパレットの透かしの帯、濃さのつまみ、選んだパーツだけ、透かし・今・差の3列の数値、契約の変更（CC-017）。

### 見た目

```
キャンバスの上:  [選択・変形][メッシュ編集]…   [透かし] 54% [全体を表示]
                                                  ↑ 押すと今の形を止めて重ねる。もう一度押すと消す

キャンバス:  今の形 ＋ 青く薄い透かし（押したときの形） ＋ 枠・ハンドル（いちばん上）

Transform（頭の変形）  パラメータ編集中は画面上で操作（数値は今の形）
  Rotation −21   ← 今のキー（顔 傾き −30）の形の値
```

## 描き方

1. 押したとき、キャンバスが最後に描いた形（`lastDeformed`）を写して止める（頂点の配列も写す）。
2. 透かしの絵は、止めた形・表示（拡大・移動）・キャンバスの大きさが変わったときだけ作る。同じ renderer で止めた形を先に描き、すぐにキャンバスの外の2Dの絵へ写して青く染め、そのあと今の形を描く（同じフレームの中なので WebGL の絵をそのまま写せる）。値やモデルを変えても、透かしの絵は作り直さない。
3. 2Dの重ね描きの最初に、透かしの絵を 35% の濃さで重ねる。そのあとに今までの重ね描き（枠・ハンドル・メッシュ・案内）を描く。

- renderer（`@app/render`）と描画の契約は変えない。2つ目の WebGL を作らないので、素材の画像を2重に持たない。
- 透かしの状態はキャンバス（`CanvasHost`）の中だけに持つ。ほかの所からは使わないので、契約（`useCanvas` など）は変えない。
