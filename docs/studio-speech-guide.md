# スタジオで文字を入力して配信する

スタジオ右側の［チャット読み上げ］で、配信者がモデルに話してほしい言葉を入力する。入力した内容をモデルが発話する機能で、自動で返事を作るものではない。liverVoiceChanger 0.9.0の読み上げ実装を統合した。

1. ［別ウィンドウで入力］で専用の入力欄を開ける。モデルを見ながら別画面に置いて入力できる。メイン側の入力欄も使える。
2. ［読み上げの出力先］にヘッドホン、または配信で使う仮想デバイスを選ぶ。マイクの選択・起動は不要。
3. ［再生方式］で［全文生成後］または［逐次再生］を選ぶ。実行中の音声を停止すると切り替えられる。
4. 入力が150ms落ち着くと、その時点の全文を裏で先行合成する。IME変換中は送らない。編集された古い生成は中断し、最新入力だけを残す。
5. ［読み上げ］、またはCtrl＋Enterで送信する。準備済み、または同じ入力を生成中なら、その音声を引き継ぐ。Enterは改行。日本語変換の確定では送信しない。1回300文字まで。
6. 入力欄の左に並ぶ感情ボタンで、［おまかせ］［うれしい］［恥ずかしい］［やさしい］［寂しい］［驚き］［ささやき］を選ぶ。選択はメインと別入力窓で共通。入力中の先行合成も選択した感情を使い、感情を変えると古い下書き音声を使わず生成し直す。［おまかせ］は従来の「文脈に合わせる」で、全文と直前3件の完了した発話に合わせた読み方をモデルへ指示する。
7. 必要なら［場面・話し方］へ「落ち込んだ友人を励ます」などと入力する。［大切なことを伝える］［話題を切り替える］は、会話の声量と普段の声の高さを保ち、芯・響き、言葉の置き方や短い間を意識する指示を入れる。両方の入力画面で使える。これらの例を選ぶと感情は［おまかせ］に戻る。
8. ［読み上げを停止］は生成中と再生中の両方で使える。ミュートは再生中も反映する。生成中も次の文章を書ける。

［全文生成後］は全文の完成後に再生し、［逐次再生］は生成できた部分を順番に再生する。どちらも送信した全文をモデルへ渡して抑揚を計画する。初回はモデルの読み込みも必要。逐次再生は、文章の長さ・直近の読み上げ速度・今回の合成速度に合わせ、最低1秒以上の音声をためてから開始する。長い文章を実時間より遅く合成する場合は、途中の待ちを減らすため開始前の準備を長く取る。［音声をためています…］の間も次の文章を入力できる。準備済みの先行合成はすぐ再生できる。途中でGPU負荷が急変した場合の待ちは残り得る。語尾の残り音声と終了通知はまとめて扱う。[途切れの修正と実測](evidence/studio-speech-continuity-2026-10-16/README.md)、[合成速度の比較](evidence/studio-speech-latency-2026-10-16/README.md)。

別ウィンドウは同時に一つだけ開く。再びボタンを押すと既存の入力欄へ移る。ウィンドウを閉じても実行中の読み上げは続き、メイン画面から停止・ミュートできる。メイン画面を閉じると入力ウィンドウも閉じる。閉じた入力欄の下書きは破棄する。

メイン画面を閉じると、別入力窓・映像出力窓が残っていても、アプリ全体と専用の音声処理を終了し、読み上げモデルもGPUから解放する。終了前に［読み上げモデルを解放］を押す必要はない。終了中に届いた先行合成などの要求でモデルを再起動しない。

先行合成中は無音で、口も動かさない。音声を再生するのは送信後。先の文章を推測して付け足すことはない。送信時に文章・感情・話者・声質設定・文脈が異なれば先行結果を使わず、現在の入力から生成する。場面への適合・読み間違い・声の自然さは試聴して確認する。

［恥ずかしい］では、口ごもる演技として短い言い直しやためらいを自動で最大2箇所に加える。例:「あなたのことが大好きです」→「あ、あなたのことが…だ、大好きです」。既に書かれた言い直しは重ねず、読みが曖昧な漢字や名前の言い出しは「あ……」のようなためらいを使う。履歴・文脈は入力した原文のまま。他の感情では文字を加工しない。演技を含む全文を同じ声で一度に合成し、その音声へ以下の処理を加える。話者の参照声や声質設定は変更しない。

「あ・い・う・え・お」は、つまり音だけでなく、その後の本文の最初の母音も、それぞれの響きを残した息へ近づける。「い（息）、い（息）きます」「う（息）、う（息）ん」のような扱い。本文側は短い母音を判別できる範囲だけを処理し、後続の子音や単語全体を息に変えない。つまり音と本文の間は約0.7秒以上を目安に確保する。語尾は声を徐々に弱めながら息へ移し、長い間のある句の終わりと文末で息が抜けるようにつなぐ。発話全体の速さも通常の88％に落とす。単純な低速再生で声の高さを下げる処理ではない。

全文・逐次・入力中の先行生成で共通。発話する語は保持するが、音声の長さは広げた間と遅いテンポの分だけ増える。「ぁっ・・・」のように自分で書いた言い出しは重ねて増やさない。合成へ渡す演技には間を補い、特に「う、うん」が一続きになったり後半が省略されたりしないよう、冒頭のためらいを短く止める指定にする。入力本文と履歴はそのまま。追加のAIモデルや通信は不要。[実装・動作確認](evidence/studio-speech-shy-delivery-2026-10-16/README.md)。

通常は短い音声区間ごとに処理する。「い」などの言い出しが遅い場合、本文の母音の境界を待つ場合、語尾の減衰を確認する場合は、先行生成がまだ終わっていないと再生開始が遅くなることがある。判別できない母音は元の音を保つ。息は生成音からの近似で、演技の聴感には合成モデルによる幅がある。以前提示した[5母音の音声](evidence/studio-speech-vowels-2026-10-16/README.md)も［恥ずかしい］を選んだものだったが、当時はつまり音の吐息処理が中心で、今回の本文の出だし・語尾・間・テンポの変更は含まれていない。

## 声とモデルの口

話者は［マイク・音声］で選択中の参照WAVに固定する。同じ参照音声から作った話者プロンプトを、文章が変わっても使い回す。参照WAVのhashも照合する。以前のように発話ごとに声の説明から別の声を作る処理は行わない。話者を変えるときは音声変換側の参照声を明示的に変更する。

音声の分割処理も発話中の状態を連続して保持する。「みんなのことがすきです」の途中だけ声が極端に低くなる条件を再現し、分割した波形の復元処理を修正した。全文・逐次の両方に適用する。[修正と比較](evidence/studio-speech-register-2026-10-16/README.md)。

［マイク・音声］の明るさ・厚み・柔らかさ・出力フィルタ・出力ゲインを常に同じ設定で適用する。話者の基準と声質設定は文章・文脈の指示から分離し、場面に応じた抑揚を声の作り直しで表現しない。入力雑音除去・発話判定は使わない。異なる合成方式なので、音声変換の出力と完全に同じ波形を作るものではない。

［マイク・音声］の［口の動き］で［音声出力と口を連動］がONなら、読み上げも最終出力PCMの再生時刻で口へ渡す。既存の口の開閉・母音口形を使い、ミュート・停止では閉じる。モデルに口の動きが無い場合は同パネルからモデリングへ移動して設定する。

マイク変換と読み上げは交互に使う。実行中の音声を止めて切り替える。読み上げモデルは次の発話でも再利用する。両方式とも通常停止ではモデルを保持し、［読み上げモデルを解放］で解放する。メイン画面では［声と読み上げの設定］のすぐ下、別入力ウィンドウでは最下部の［発話履歴をクリア］の隣にある。先行合成中も解放でき、その後は入力が変わるまで再生成しない。初回読込中など3秒で中断できない場合は専用プロセスを終了して解放する。マイク変換・WAV変換の開始時も解放する。

配信の音声は、仮想デバイスの出力先とOBS等の入力先を合わせて取り込む。Spout2は映像の経路なので音声を別に設定する。

## 保存と準備

音声変換と共通の参照音声・声質設定、読み方・場面・文脈・再生方式をプロジェクトに保存する。旧設定の「声の説明」とフィルタ適用フラグは形式互換のため保持するが、話者の作り直しや共通の声質調整の解除には使わない。旧プロジェクトの既定は［全文生成後］。下書き・発話履歴・生成音声は次回起動へ保存しない。発話履歴は最大20件、文脈に使うのは直前3件の最後まで再生した発話。途中停止した発話は次回の文脈へ渡さない。履歴のクリアとプロジェクト切替でも消す。

読み上げには別環境 `.venv-voice-design` と固定版Qwen3-TTS Base 1.7Bを使う。このPCではliverVoiceChangerのPython環境とStudio内のモデルキャッシュを利用する。VoiceDesignは既存の参照声の作成履歴として残り、発話ごとの合成には使わない。通常の生成はオフラインで、文章や音声を外部へ送信しない。

別のPCでは［音声の実行環境］に指定したモデル保存先と同じフォルダへ、次のスクリプトで導入する。

```powershell
tools/voice-engine/setup-speech.ps1 -PythonExecutable C:\Python312\python.exe -RuntimeDirectory <音声のモデル保存先>
```

CUDA対応GPUが必要。準備・機器を変更したあとはスタジオを開き直す。生成の診断ログはアプリデータの `voice/logs/speech.log`。一時要求・一時WAVは生成完了・停止で削除する。
