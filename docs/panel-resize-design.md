# パネルの境目で大きさを変える（設計）

2026-10-12 CL。ユーザーの要望（課題は I-087）。2026-10-12 CO: 続きの実装指示を受け、推奨D1〜D5=Aで実装する。

## 実装時に決めたこと（2026-10-12 CO）

- 列と作業エリアの境目は既存の境界線に6pxの操作帯を重ねる。既定の280pxや作業エリアの幅は、大きい窓ではそのまま。窓が狭いときは右の列、次に左の列を縮め、中央320pxを残す。表示のための縮小で記録した幅を書き換えない。
- `live2d-studio.layoutSizes`に`モード.境目`をキーとして保存する。旧`panelHeights`は、以前適用していた右の共通パレットの値を移して消す。リセット後に古い値が復活しない。
- 左・右・オブジェクトパレットの高さは60〜4000px。スタジオの下のパネルは各200pxを保ち、中央が400pxより狭いときは下の列を横スクロールできる。
- アニメーションの幅が600px以下のときは、スライダーを上下に並べ、その高さも変更できる。幅と高さは別に覚える（高さは80px以上、プレビューも80px以上）。タイムラインは120px以上、上の領域は200px以上を残す。
- ドラッグは離したときだけ保存し、Esc・pointercancel・フォーカス喪失・窓の制約変更・画面を離れたときに取り消す。ダブルクリックはその境目だけ、メニューは全モードのサイズを戻す。たたみの記録は保つ。
- 契約とProject・Environment・schemaVersionは変更しない。検証と画面の証跡は[検証記録](evidence/panel-resize-2026-10-12/README.md)にまとめる。

## 解決したいこと

ユーザーの言葉:

> パネルの表示範囲を変更できるようにパネルとパネルの境目で上下できるようにしたい。ツールパネルや、編集ウィンドウ、アニメーションもスタジオも。全般的に。

モデリング・アニメーション・スタジオのどの画面でも、パネルとパネル、パネルと作業エリア（キャンバス・プレビュー）の境目をドラッグして、大きさを変えられるようにする。変えた大きさは次に起動しても残す。

覚え方: たたみ（`live2d-studio.collapsedPanels`）と高さ（`live2d-studio.panelHeights`）は WebView の localStorage。高さの記録は列ごとに読んでいるので、左・下の列でも使うと、I-066（ほかの列の記録を消す）と同じことが起きる。`Layout` で1つにまとめる必要がある。

決まっていること: I-065 の設計で「キャンバス（作業エリア）の幅と高さは、今と変わらない」と決めた（パレットが出たり消えたりしても、作業エリアの大きさを変えない、という意味）。I-064 では、これを理由に列の幅を変える案を見送った。今回の要望は、ユーザーが自分で境目を動かして作業エリアの大きさを変えるものなので、この決まりを「自動では変えない。ユーザーが境目を動かしたときだけ変わる」に改める（D1）。

## 考え方

### 境目の見た目と操作（どこでも同じ）

- 境目は 6px の細い帯。マウスを乗せると色が付き、マウスの形が ↕ または ↔ になる（今の右の列の境目と同じ）。
- ドラッグで大きさを変え、離したときに決める。ダブルクリックで既定の大きさに戻す。キーボードでも ↑↓（←→）で 16px ずつ（Shift で 64px）。
- 決めた大きさは、モードごと・境目ごとに覚える（D2）。
- 最小・最大を決め、作業エリアが狭くなりすぎないようにする（作業エリアの幅は最低 320px・高さは最低 200px。列の幅は 200〜560px）。窓を小さくしたときは、列から先に縮める。

### 足す境目（D3）

| 境目                                                 | 向き | 既定             | 範囲                  |
| ---------------------------------------------------- | ---- | ---------------- | --------------------- |
| 左の列と作業エリアの間（全モード）                   | ↔    | 280px            | 200〜560px            |
| 作業エリアと右の列の間（全モード）                   | ↔    | 280px            | 200〜560px            |
| 左の列のパネルの下（モデリングの素材・パーツなど）   | ↕    | 中身に合わせる   | 60px〜                |
| 右の列のオブジェクトパレットの下                     | ↕    | 中身をすべて出す | 60px〜（D4）          |
| 作業エリアと下の列の間（スタジオ）                   | ↕    | 220px            | 120px〜窓の高さの 60% |
| 下の列のパネルの間（スタジオの表情・アニメーション） | ↔    | 半分ずつ         | 各 200px〜            |
| アニメーションのプレビューとタイムライン             | ↕    | 40%              | 120px〜               |
| アニメーションのプレビューとスライダー               | ↔    | 260px            | 180〜480px            |

右の列の共通パレットの下の境目は、今のまま。

```
┌ ☰ ─ モデリング アニメーション スタジオ ──────────────────────────────┐
│ 素材        ║ [ツール]                                   ║ パラメータ  │
│             ║                                            ║             │
│═════════════║        作業エリア（キャンバス）            ║═════════════│ ← パネルの下の境目（↕）
│ パーツ      ║                                            ║ Transform   │
│             ║                                            ║═════════════│
│             ║                                            ║ パーツの設定 │
└─────────────╨────────────────────────────────────────────╨─────────────┘
              ↑ 列の幅の境目（↔）                           ↑
```

### 戻し方

メニュー（☰）に［パネルの配置を元に戻す］を足し、すべての境目を既定に戻す（たたみはそのまま）。

### 覚える所（D5）

今のたたみ・高さと同じく WebView の localStorage に覚える（キー `live2d-studio.layoutSizes`、境目の id → px）。`Layout` で1つにまとめ、どの列から変えても、ほかの記録を消さない（I-066 と同じ作り）。今の `live2d-studio.panelHeights` は読み込んで移す。

## テストと確認

- 単体: 境目ごとのドラッグ・キー・ダブルクリック、最小・最大、窓を小さくしたときの縮み方、記録の保存と読み込み（ほかの列の記録を消さない、古い `panelHeights` を移す、壊れた値）、［パネルの配置を元に戻す］。
- 直す既存のテスト: `Layout.c61.test.tsx`（右の列の幅 280px を確かめている所。既定のときは 280px のまま）、`panelHeight.test.tsx`（境目は右の列の共通パレットだけ、を確かめている所）。
- 画面: 開発サーバーで 1440×1000・800×600。モデリングで列の幅と素材・パーツの境目、アニメーションでタイムラインの境目、スタジオで下の列の境目を動かし、作業エリアの絵が崩れずに描き直されること、再読み込みで残ることを画像に残す。
- 小さい窓（800×600、本番アプリの最小 960×600）で、作業エリアが最低の大きさを保つこと。

## 完成の条件

- モデリング・アニメーション・スタジオのどの画面でも、パネルとパネル・パネルと作業エリアの境目をドラッグして大きさを変えられる。
- 変えた大きさは再起動しても残り、ダブルクリックやメニューで既定に戻せる。
- 境目を動かさない限り、今と同じ大きさで表示される。
