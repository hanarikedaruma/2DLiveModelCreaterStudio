# 操作中の対象を固定する（設計）

2026-10-11 CL。ユーザーの要望（課題は I-069）。末尾の「決めたこと」で設計を確定した（同日、すべて推奨のとおり）。実装で設計から変えた点は「実装で決めたこと」に書く。

## 解決したいこと

ユーザーの言葉:

> 変形やワープなど何かツールを使用しているとき、ほかの要素の範囲を選択すると、そちらの編集状態になりますが、例えば変形時の、回転中心の◎をドラッグしようとすると背景のパーツにフォーカスされてしまって、操作できない。何かを操作中、ほか要素に勝手に切り替わるのをやめたい。右クリックで解除してからか、要素の操作範囲からある程度外側のものを選択した時に切り替えが起きるようにしたい。変形ツールで移動を行いたいときに、線を掴めず後ろ側のパーツを掴んでしまうなどの操作ストレスを軽減したい。

これを、次の3つにまとめる。

1. ツールで何かを操作しているとき、近くの別のパーツを押しても、そちらに切り替わらないようにする。
2. 切り替えるのは、右クリックで外してから、または操作範囲からある程度外を押したときにする。
3. 変形ツールで ◎ や枠をつかみたいのに、後ろや手前のパーツを選んでしまうことを無くす。

| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |

押した点のパーツは `hitTestItems` で決まる。変形後のメッシュの三角形に点が入る、いちばん手前のロックしていないパーツ。メッシュは不透明な所より 3〜7px 外まで張ってあるので、絵の縁のすぐ外も、そのパーツの上として扱われる。

## 考え方

### 操作範囲

選んでいるものを操作できる所を「操作範囲」とし、そのまわりに余白（画面の 24px。D2）を足す。

| ツール               | 操作範囲                                                |
| -------------------- | ------------------------------------------------------- |
| 選択・変形           | 選んでいる枠（向きのある四角）、回転・拡縮のハンドル、◎ |
| メッシュ編集・輪郭線 | 対象のメッシュ（変形後の三角形）、頂点・線の点          |
| ワープ               | 格子（変形後の格子の外周）、制御点                      |

余白は画面のピクセルで決めるので、拡大縮小しても指で押す感覚は同じになる。

```
              ○ ← 回転のハンドル
              │
     ┌ ─ ─ ─ ─┼─ ─ ─ ─ ┐ ← 余白（24px）。ここまでは、選んでいるものの操作
       ■──────■──────■
     ╎ │               │ ╎
       ■       ◎       ■   ← 枠の中: 移動。後ろや手前に別のパーツがあっても切り替えない
     ╎ │               │ ╎
       ■──────■──────■
     └ ─ ─ ─ ─ ─ ─ ─ ─ ┘
   この外を押すと、押した所のパーツへ切り替える（何も無ければ選択を外す）
```

◎ が枠の外にあるとき（腕の付け根など）は、◎ のまわりも操作範囲に入れる。

### 押したときの決まり（全ツール共通）

| 押した所                  | 今                                             | これから                                                               |
| ------------------------- | ---------------------------------------------- | ---------------------------------------------------------------------- |
| 操作範囲と余白の中        | その点に別のパーツがあれば、そちらへ切り替わる | 選んでいるものの操作。切り替えない                                     |
| 範囲の中で Shift+クリック | 押した所のパーツを足す・外す（選択・変形）     | 今と同じ（足す・外すは、はっきりした操作なので）                       |
| 範囲の中で Ctrl+クリック  | （無い）                                       | 押した所のパーツへ切り替える（D3）                                     |
| 余白より外のパーツ        | 切り替える                                     | 切り替える（D1）。選択・変形では、最初の操作は選ぶだけ（I-050 のまま） |
| 余白より外の何も無い所    | 選択を外す（メッシュ・ワープ・輪郭線は2段）    | 今と同じ                                                               |
| 右クリック                | 選択を外し、対象を選ぶ段へ                     | 今と同じ                                                               |
| 何も選んでいないとき      | 押した所のパーツを選び、そのまま動かせる       | 今と同じ                                                               |

大きなグループ（体など）を選ぶと、キャンバスのほとんどが操作範囲になり、押しても中のパーツに切り替わらない。そのときは右クリックで外すか、Ctrl+クリックか、左の列のパーツの一覧で選ぶ。

### 選択・変形ツールの押した所の調べ方（新）

1. **ハンドル**: 回転（11px）・拡縮（11px）・◎（11px に広げる。D4）。動かせない ◎ を押したときは、選んでいるものの移動になる（今と同じ。D5）。後ろのパーツには切り替えない。枠が小さいときは今と同じく、◎ と拡縮はつかまずに移動にする。
2. **Ctrl+クリック**: 押した所のパーツへ切り替える（D3）。
3. **Shift+クリック**: 今と同じ（押した所のパーツを足す・外す）。
4. **操作範囲と余白の中**: 選んでいるものの移動。押した所が選んでいるパーツの1つ（複数選択）なら、動かさずに離したとき、それだけを選ぶ（今と同じ）。
5. **余白より外**: 今と同じ（パーツがあれば切り替える。最初の操作は選ぶだけ。何も無ければ外す）。

複数を選んでいるときの枠は、今と同じく主のパーツの向きで全部を囲む枠。

### メッシュ編集・ワープ・輪郭線

- 操作範囲と余白の中を押したときは、頂点・制御点・線の点の選択を外すだけで、パーツは切り替えない（今の「メッシュの中」と同じ扱いを、余白まで広げる）。
- 余白より外は今と同じ（パレットの設計の D1 の切り替え）。右クリックも今と同じ。
- 何も無い所からのドラッグ（囲んで選ぶ）は今と同じ。

### 押すと何が起きるかを見せる

- **マウスの形**（D6。選択・変形ツール）: 範囲の中は移動の形（move）、拡縮のハンドルは枠の向きに合った矢印、回転のハンドルと ◎ はつかむ形（grab）、余白より外は矢印（default）。
- **切り替わる先の予告**（D7。選択・変形・メッシュ編集・ワープ・輪郭線）: 余白より外で別のパーツの上にマウスがあるとき、そのパーツを点線で囲み、名前を出す（対象を選ぶ段と同じ見た目）。範囲の中では出さない。
- 余白の線そのものは描かない（画面がうるさくなるため）。マウスの形と予告で分かるようにする。

## 完成の条件

- 変形ツールで顔を選んでいるとき、◎ を押すとつかめる。動かせないときも、後ろのパーツに切り替わらない。

## 実装で決めたこと（2026-10-11）

- **Ctrl+クリック**: 何も無い所を Ctrl+クリックしたときは、選択を外す（押した所のものを選ぶ、の延長）。Ctrl を押している間はハンドルをつかまない（◎ の上でも、その下のパーツを選べる）。
- **操作範囲**: 選択・変形では、枠と余白に加えて、回転のハンドル（つかめる 11px）、主の ◎ と、複数選択のほかのパーツの ◎ のまわり（余白の 24px）を入れた。メッシュ編集でメッシュの無いパーツは、パーツの外接矩形と余白。ワープは格子の外周と、グループの外接矩形の両方（格子の無いグループは外接矩形だけ）。
- **範囲の中の何も無い所**: メッシュ編集・ワープ・輪郭線では、頂点・制御点・線の点の選択を外すだけで、対象の選択は外さない（2回目でも外さない）。外すのは、余白より外の何も無い所と右クリック。
- **マウスの形**: ドラッグ中は、始めたときの形のまま（移動は move、回転と ◎ は grabbing、拡縮は始めたハンドルの矢印）。プレビュー中で動かせないドラッグでは既定の形。
- **予告**: ドラッグ中は出さない。対象を選ぶ段の点線と同じ部品（`partOutline`・`drawPickOutline`）を使う。
- **◎ の説明の吹き出し**: ◎ をつかめる範囲（11px）と同じ所で出す（カード59 のテストの距離を 5・10px から 10・14px に直した）。
