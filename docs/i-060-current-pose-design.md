# 現在の姿勢からアニメーションを再生する（I-060）

2026-10-12 CO。ユーザーの「先にI-060を進めて」と、選択した「今の姿勢を始点に、記録した動きの変化量を重ねる」に基づく。契約CC-023、保存形式10。

## 再生の意味

アニメーションごとの［現在の姿勢を始点にする（実験）］をONにすると、スタジオで再生ボタンを押すたびに、直前に表示した姿勢を開始点として取る。記録した先頭の値へ移動せず、そこからの変化量を重ねる。たとえば記録が顔左右−10→0、開始姿勢が18なら、18→28になる。パラメータの範囲を超えた値は丸める。

キーのあるパラメータだけを対象にする。キーの無い軸は表情・入力・周期の動きを継続する。通常の「上書き」は開始点を保ち、「トラッキングに加算」は開始後の顔・体の入力変化も重ねる。［始まり］の秒数と曲線は記録した変化量に掛ける。速度は素材の時間へ掛ける。

途中で切り替える場合も、直前のアニメーションを含む表示姿勢を取り、次の再生の開始点にする。新しい対象の軸は重み1で上書きするので、前のフェードが二重に混ざらない。停止・終端の復帰は従来の［終わり］の秒数で最新の入力へ戻る。ループの変化量は常に記録した先頭から求め、周回ごとに加算しない。素材の先頭と末尾が異なるループの境界は、その差だけ戻る。

## 合成と物理

スタジオ実行部は直前フレームの「アニメーションの層までの合成値」と、その後のリップシンク・物理の実際の差を別々に持つ。表情や周期の値を再び足さず、リップシンクを維持する場合は通常の層を継続する。維持OFFでは最後に表示した口の値を開始点へ取り込み、リップシンクを止める。

物理の出力を直接記録したトラックは、その直前の表示値から相対再生し、物理で上書きしない。胸の出力は対になる軸も開始点へ取り込む。物理を維持する場合は他の揺れを継続する。維持OFFでは直前の実際の出力を保持して積分を止める。流れ線は表示した曲がりを保持し、基準線の移動・回転・長さに追従する。すでに非表示になった揺れを後の再生で復活させない。

この履歴は実行部だけの一時状態で、Projectには保存しない。作品の読み込み、実行部の終了、サービスの切り替え、時刻逆行で取り直す。開始姿勢を保存するために頂点・ワープ・キーを書き換えない。

## 画面と保存

- アニメーションの［登録の設定］→［遷移］に実験設定とⓘを追加する。既存作品と新規素材はOFF。1回のUndo/Redoで切り替える。
- スタジオのボタンに［今の姿勢から］を表示する。設定変更は次の再生開始時に反映する。
- タイムラインは記録値を編集・再生する。アニメーション素材の書き出しも記録値を使う。スタジオのプレビューと出力先には同じ相対再生のフレームを送る。
- 周期アニメーションは元の役割を保つため対象外。設定欄を無効にする。
- `Animation.transition.startFromCurrent?: boolean`。省略・falseは従来の再生。保存形式9→10の移行は既存のトラック・遷移・モデルを変更しない。

## 確認すること

- 非ゼロの先頭、表情と入力の合成、途中の切り替え、開始後の入力変化、開始フェード、速度、範囲、停止、ループ、再開始無視、削除・別作品・時刻逆行。
- 開始前後で実際の全描画頂点が一致し、その後に記録した差で動く。リップシンク・周期・物理の値を二重に足さない。停止した揺れの保持と再開。
- 実画面で設定・ⓘ・ボタン・Undo/Redo、旧作品・設定ON/OFFの保存再読込。EdgeとWebView2の大小2サイズ、制作モデルの写し。
