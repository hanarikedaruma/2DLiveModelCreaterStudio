## 試作（このモデルで実装して確かめた）

試作はモデルの組み立てスクリプトに入っている。`projects/cardigan-bob-20261010/build.ts` の「face turn」の節と、`authoring/turnref.py`・`turnfit.py`・`headturn.json`。このフォルダは Git の管理外。

**手順**

1. **参考画像を作る。** 左右それぞれ2枚生成し、良い方を選んだ。
2. **体に合わせて置く。** 肩の外側の縁を使い、倍率と位置を合わせた。肌の多い所は特徴点が取れず、特徴点では合わなかった。
3. **対応を取る。**
   - 頭の範囲の特徴点（SIFT の相互一致）を、その点でいちばん手前に描かれているパーツの層に振り分ける。
   - 層ごとに外れ値を除く。
   - あごの線は、元画像と参考画像の両方で左端・あご先・右端を指定し、その間の最も暗い線をなぞった。
4. **層ごとの動きの場を当てはめる。** 顔（目鼻口・頬を含む）と前髪は薄板スプライン、髪飾りはアフィン。
5. **量をそろえる。** 参考画像は、左右で回り方が違った（近い側の目が 64px と 80px 動いていた）。どちらも、近い側の目が ±30 で 30px 動くように縮めた。
6. **対応点の少ない層は、規則で動かす。**
   - 横髪・耳・耳飾り・耳の後ろの髪: 同じ高さの頬の縁の動き × 係数（房 0.9、耳 0.55〜0.6）
   - 後ろ髪: 頭頂の動き × 0.7 を、毛先で 0 にする
   - 首: 輪郭は動かさず、内側（あごの下の影）だけをあごに付けて動かす
7. **頂点のキーにする。** FaceAngleX の −30〜30 を 10 刻みで作り、斜めは和を 0.75 倍にした。FaceAngleY は今のまま。

**試作で残った課題**

- **生成した参考画像のばらつき:** 毎回違い、回す量や頭の位置もずれる。右向きの1枚目は、あごが大きく動きすぎて使わなかった。複数作って選ぶことと、量を正規化することが要る。
- **対応点の不足:** 肌と髪の平らな所は特徴点が取れない（横髪は 0〜3 点）。規則か手で補う必要がある。
- **あごの線の端点:** 手で指定した。
- **耳 L の前後:** 前髪より手前に描いているので、遠い側に回っても顔に隠れない。前後の入れ替えは I-039 の残り。
- **作り方:** 試作はモデルの組み立てスクリプトの中にあり、アプリの画面からは作ることも直すこともできない。

## 直し方（案）

### A. かんたんセットアップの顔の向きを直す（参考画像なしで、全モデルに効く）

1. **頭の傾きに合わせる。** 両目（白目）の中心を結ぶ線から頭の傾きを求める。その傾いた座標で頭の形を作り、横の動きを頭の向きに沿わせる。
2. **あごと輪郭も動かす。** 頭の形の下端をあごより下（顔の高さ × 0.45 程度）まで伸ばし、あご先が鼻と同じ向きへ動くようにする。
3. **近い側と遠い側を分ける。** 横の動きを「頭を円柱とみなした回転」で計算する。近い側の頬の縁は向きへ動き、遠い側の縁は頭の輪郭の近くで止まる。
4. **量の決め方を変える。**
   - まつげの先のような細い部品で上限が決まらないよう、目の位置は白目・瞳で見る。
   - 量は角度ではなく「±30 で近い側の目が動く距離 = 顔の幅 × 割合」で決める（D3）。
5. **層の規則を変える。**
   - 横髪・耳・耳の子（耳飾りなど）・耳の近くの自由パーツ: 向きと逆へ動かすのをやめ、同じ高さの頬の縁の動き × 係数で動かす（耳 0.6、横髪 0.9）。
   - 後ろ髪: 頭頂を向きへ回し、毛先は動かさない。
6. **首の影をあごに付ける。** 首は頭の外にあるので、首のメッシュにも FaceAngleX の頂点のキーを作る。首の画像の上部の内側だけをあごの動きに付けて動かし、首の輪郭は動かさない。
7. **付き方を手で変えられるようにする（D4）。** パーツの設定（詳細モード）に「顔の向きでの付き方」を出す。選べるのは、表面に沿う／縁に付く × 係数／頭頂から／動かない。

### B. 参考画像に合わせて顔の向きを作る（新しい機能）

1. **読み込む。** 頭の変形グループを選んだときに「顔の向き」のオブジェクトパレットを出し、左向き・右向きの参考画像を読み込む。
2. **位置を合わせる。** 肩・鎖骨など回らない所で自動で合わせる。ずれていれば、倍率と位置を手で直す。
3. **対応を取る。**
   - 特徴点は自動で取る。アプリには OpenCV が無いので、画像の小片の照合（正規化相互相関）で行う。試作は Python の SIFT を使った。
   - あごの線は、元の絵と参考画像の両方で3点（左端・あご先・右端）をクリックして指定する。
   - 足りない所には、ピンを足して手で指定する。
4. **量を決める。** 「±30 で近い側の目が動く距離」のスライダーで、参考画像の回り方のどれだけを使うかを決める。
5. **重ねて比べる。** キャンバスに参考画像を半透明で重ね、FaceAngleX を ±30 にして比べる。
6. **キーを作る。** 層ごとの場と、対応点の少ない層には A の規則を使って FaceAngleX のキーを作る。手で直したキーとロックしたキーは残す。
7. **参考画像はアプリの外で作る。** アプリは外部に接続しない（2026-10-03 の決定）。プロンプト集（`docs/part-image-prompts.md`）に「左右を向いた参考画像」のプロンプトを足す。中身は次のとおり。
   - 元画像を添付する。
   - 頭だけを回し、肩は動かさない。
   - 背景は白にする。
   - 複数作って選ぶ。

基準の形の直し（配置）: 下まぶた R の位置、耳の大きさ、ハイライト L、耳の後ろの髪、跳ね毛。これは[配置の手順](../tools/model-authoring/README.md)のグリッドの確かめで防ぐ。頭の変形 8° と目の変形 L −7.8° の回転は、意図をユーザーに確かめる。

### 自動にする規則（A に足す案）

かんたんセットアップの顔の向き（A1〜A7）に、次を足す。量は、このモデルでユーザーが決めた最終的な動きを、顔の幅・白目の大きさに対する割合にしたもの（ほかのモデルにも使える形）。

- **A9 耳の大きさ:** ±30 で、見える側の耳を 1.15 倍、隠れる側の耳を 0.94 倍にする。耳の動きは頬の縁の動き × 0.45（今の案 A5 の 0.6 より小さく）。
- **A10 前髪:** 横は顔の表面の動き × 0.55、上へ顔の幅 × 2%、幅 0.97。上下では顔と同じ向きに × 1.2、高さ 1.02〜1.08。

- **A13 視線の幅:** 瞳の動く幅を、白目の大きさから決める（横は白目の幅 × 0.25、縦は白目の高さ × 0.38）。ハイライトは瞳の 0.3 倍。
- **A14 跳ね毛などの房:** 自動では今のまま（付いている髪に付いて動く）。このモデルの直しは好みとみて、規則にしない（D13）。

作り方の決まり:

1. **ワープは目の遠近（A8）だけで使う**（D11）。目のグループは標準の階層にあるので、グループは新しく作らない。目の部品がまとめて詰まり、ユーザーがあとで制御点で直せる。目のグループにワープがもうあれば（このモデル）、それを使う。
2. **ほかは、今の自動と同じく頂点のキーで作る。** ユーザーが前髪・瞳・白目などで作った「パーツ1つだけのグループ」は、ワープを付けるための手段とみる。自動では作らない（階層を変えない）。手で直すときは、今と同じくグループを作ってワープを足せる。画像パーツにワープを付けられるようになったら（I-079）、見直す。
3. **キーは 0 と ±30 だけにする。** ユーザーは中間のキー（±10・±20）を消して、±30 だけで直していた。その間は直線で補間する。斜め（左右と上下を同時）の補正のキーは今のまま。
4. **量は、そのモデルの大きさに対する割合**（顔の幅 W、目の幅、白目の大きさ、パーツの幅）。
5. **手で直したキー・ロックしたキーは残す**（今と同じ）。かんたんセットアップを押し直すと、自動のキーだけが新しい形になる。
