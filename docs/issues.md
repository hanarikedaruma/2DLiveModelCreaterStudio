## I-001 カメラによっては 1280×720 で映像が遅い

- 現象: eMeet C980 Pro でトラッキングが 12.9fps（目標 30fps 以上）。動きがカクつく。
- 原因: カメラが 1280×720 のとき毎秒13枚しか映像を出さない（設定上は 30fps を返す）。640×480 と 1920×1080 では 25fps、内蔵の HD Webcam は 1280×720 で 29.5fps。推定を止めてカメラの映像だけを数えても同じなので、アプリ側ではない。詳しくは docs/studio-check.md の「2026-10-03 の計測」。
- 対応案: トラッキングの設定に解像度の選択（640×480 / 1280×720 / 1920×1080）を足す。または 1280×720 で始めて、届く映像が遅ければほかの解像度を試す。
- 判断が要る点: 設計書（カード15）は「1280×720・30fps を優先」と決めている。変えるなら設計書からの変更として docs/status.md に残す。
- 関連: packages/tracking/src/source/camera.ts の `cameraConstraints`、完成条件17（docs/acceptance-mvp.md）。

## I-002 カメラから届いている映像の fps が画面で分からない

- 現象: I-001 のような、カメラ側の遅さに利用者が気づけない。計測の表示（Ctrl+Shift+D）のトラッキングの fps は推定した回数で、カメラの遅さと推定の遅さを区別できない。
- 対応案: 計測の表示に、カメラから届く映像の fps（MediaStreamTrack の stats、または requestVideoFrameCallback の presentedFrames）と解像度を出す。遅いときはトラッキングの設定に注意書きを出す。
- 関連: apps/desktop/src/diagnostics/、packages/tracking/src/source/source.ts。

## I-003 大きな PSD を取り込むとメモリが多い

- 現象: 4000×6000px・100レイヤーの PSD（132MB）で、取り込みの前 381MB → 取り込みの後 1,759MB → 割り当ての後 1,984MB。
- 原因: 素材の置き場（createAssetRepository）が、素材ごとに ImageBitmap と ImageData（メッシュの生成用）の両方を持ち続ける。
- 対応案: ImageData はメッシュを作るときだけ作って捨てる。
- 関連: packages/contracts/src/assets.ts、docs/measurements/stress-2026-10-03T07-27-18-443Z.json。

## I-004 大きな PSD の取り込み中に画面が止まる

- 現象: 上の PSD の取り込み（解析・トリミング・PNG にする）に 9.2秒かかり、その間は画面が反応しない。
- 原因: PSD の取り込みがメインスレッドで同期に動く。
- 対応案: 取り込みを Web Worker に移し、進み具合を出す。
- 関連: packages/io/src/import/。

## I-005 顔の推定と描画が重なったフレームが遅い

- 現象: スタジオの描画は平均 154〜162fps だが、遅いほうから1%のフレームの平均は 45fps 前後。60Hz の画面なら1フレーム落ちる程度で、目標（平均 60fps）は満たす。
- 原因（見立て）: MediaPipe の推定（1枚 10ms 前後）がメインスレッドで同期に動き、そのフレームの描画が遅れる。
- 対応案: 推定を Worker に移す（MediaPipe の Worker 対応と、映像を Worker へ渡す方法を調べる）。急がない。

## I-006 左右反転コピーで FaceAngleX のキーの符号を反転してよいか

## I-007 計測の表示にパラメータの値が出ない

## I-008 かんたんモードでも「ワープ編集」のツールのボタンが出る

- 対応案: CanvasTool に level（easy / detail / both）を足す（shell の差し込み口の変更）。または、かんたんモードではツールを選べない表示にする。
- 関連: apps/desktop/src/shell/api.ts、apps/desktop/src/modes/modeling/warp/。

- 対応（2026-10-05）: キャンバスのツールに level（かんたん/詳細）を足し、ワープ編集は詳細でだけ出す。使っているツールが出ないほうになったら既定のツールに戻す（契約の変更 CC-001。shell/canvas/toolLevel.test.tsx）。コミット a9c520b（ブランチ fix/issue-bugs）
