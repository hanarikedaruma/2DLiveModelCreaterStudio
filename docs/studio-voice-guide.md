# スタジオで声と口を設定する

文字を入力して配信する場合は［チャット読み上げ］を使う。[読み上げの使い方](studio-speech-guide.md)。

## 最初に使う

1. ［スタジオ］右側の［マイク・音声］パネルを開き、［入出力］でマイクとヘッドホン出力を選ぶ。
2. ［声の調整］で声と品質を選び、［音声と口の動きを開始］を押す。モデルの準備中は数秒から十数秒待つ。
3. 中央のモデルを見ながら、声の明るさ・厚み・柔らかさとフィルタを調整する。

モデルに口の開閉が無い場合は、［口の動き］の［口の開閉を作る］からモデリングへ移動する。既存の口形があるモデルはそのまま使える。音声と連動する間も、顔や目のカメラ追跡は使える。

［マイク・音声］は［スタジオの設定］から独立している。題名で折りたたみ、下の境目をドラッグして高さを調整できる。パネルをたたんでも実行中の音声は続く。

## 声・フィルタを調整する

［声の調整］の3つの声質項目、入力ゲイン、フィルタは実行中にも変更できる。AI方式・品質・参照WAV・雑音対策・機器・専用の出力ゲインは停止して変更する。実行中の出力音量はゲインフィルタで調整できる。

フィルタは5種類、最大8個。上から順に適用し、同じ種類も複数追加できる。全体と各項目をON/OFFし、↑↓で順序を変える。全体OFFは変換済みの声で比較する。［元の声を試聴］は別の操作で、遅延を合わせた元音声に切り替わる。

初期の声は架空の日本語女性声。別の目標声は［参照WAVを取り込む］から選ぶ。1〜120秒、mono/stereo、192kHz以下、256MB以内の声だけのWAVを使う。［目標声を聴く］で先頭2秒を確認できる。

品質は元のVoiceChanger 0.8.0と同じ値を使う。Tinyは［最速］4ステップ/180ms、［バランス］6/240ms、［安定優先］8/300ms。大型AIは20ステップと30ステップを選べる。Tinyの再生用の余裕は40ms。［音声の計測］で現在の推定遅延を確認できる。

［音声の計測］の［不足］は、再生時刻までに次の変換音声が届かず、再生用の音声が尽きた回数。マイクの音量とは無関係で、処理の遅れにより音が途切れる状態を示す。Tinyは品質設定を保ったままGPUの実行効率を改善した。このPCの最速75秒試験では不足0・内部遅延約0.57秒を確認した。ほかのアプリとの同時使用を含む結果は、[検証記録](evidence/voice-underrun-2026-10-15/README.md)の範囲を参照する。

元のVoiceChangerと比較する際は、両方で同じ品質・参照声・声質・フィルタ・入力ゲインを選ぶ。元で［バランス］を使っていた場合は、こちらでも［バランス］を選ぶ。［声設定を取り込む］で元のAI設定JSONを読み込むと、個別の数値も引き継げる。品質を選び直すと元のプリセット値に戻る。前の統合版で保存・取り込んだ個別設定も保持するため、その設定に400ms等が含まれている場合は品質を選び直す。

［WAVで比較］は選んだ録音を同じAI・雑音・声質・フィルタ設定で変換する。処理中は中断でき、完成するまで出力先の本体ファイルを作らない。

入力メーターの［入力（調整後）］は入力ゲイン適用後の音量を示す。過大入力の表示が出る場合は入力ゲインを下げる。マイク自体で割れる場合は機器側のゲインも下げる。小さい声を拾う発話判定は判定用の音声だけを補正し、実際の入力音量を自動で上げない。

雑音除去と元音声を混ぜる時刻のずれを修正した。［声の厚み］［声の柔らかさ］を強くすると、高音に対して低音が目立つ。発音がこもる場合は、バランス品質のまま厚みを0dBへ戻し、柔らかさを少し下げて比較する。フィルタ全体OFFでも声質の3項目は残る。［元の声を試聴］ではAI生成・声質・出力フィルタを通らない元音声で比較できる。特定の「ん」の音量増加まで解消したかは[確認範囲](evidence/voice-articulation-2026-10-15/README.md)を参照する。

出力が上限を超えるときは、波形を単純に切り詰めず音量を下げて抑える。［音声の計測］で入力の過大サンプル数と出力のピーク抑制量を確認できる。音程が変わる際の電子感やゆっくりした発話の聞き取りが全て解消した保証ではなく、[公開音声での検証範囲](evidence/voice-clarity-2026-10-15/README.md)を参照する。既存の声質・フィルタ設定は保持する。

## 口の反応を合わせる

［口の動き］で［音声出力と口を連動］を選ぶ。［口の反応を合わせる］では3秒話さず、その後3秒普段の声で話す。無音のしきい値を設定し、録音ファイルは作らない。Mute中はこの調整を開始できない。

口の開きは控えめ・標準・大きめで調整する。母音口形が登録済みなら、その値を使う。形・幅の変形があるモデルには［標準の母音を設定］で初期値を入れられる。既存の登録は確認してから置き換える。推定できない発話は音量の開閉に戻る。

口は最終音声の再生時刻に合わせて動く。Mute・無音・停止・機器の異常では閉じる。同期微調整は負の値で早め、正の値で遅らせる。早める量は解析の届く時刻までに限られる。連動を外すと、音声の口レイヤーを出さずカメラの口を使える。

## 保存と配信

プロジェクトを保存すると声・フィルタ・口の設定を保存し、独自参照WAVも `voice/references/` へ写す。機器と無音しきい値はPCの設定として覚える。次回起動ではマイクを自動開始しない。

［声設定を保存］はJSONと参照WAVを別名で書き出す。別モデルでは［声設定を取り込む］からそのJSON、またはVoiceChanger 0.8系のAI設定を選ぶ。直接波形加工・旧Beatrice設定は対象外。

配信は出力先を既存の仮想デバイスの再生側にし、OBS・通話ソフトでは対応する録音側を選ぶ。Spout2は映像の経路なので、音声も別に設定する。仮想ドライバはこのアプリに含めていない。

AIが未準備なら[実行環境の準備](../tools/voice-engine/README.md)を行う。従来のマイクで口だけを動かす場合は、AI音声を停止して下の［リップシンク］を使う。
