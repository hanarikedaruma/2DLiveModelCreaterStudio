## 約束（設計どおり。実装で決めた細部を含む）

- **設定**：`setSettings` は `Project.armTracking` を書き換えるコマンド（「腕・手の設定を変更」）を送る。1回の Undo で戻る（判断1）。同じ値なら送らない。
- **体の推定を動かす条件**（判断2）：実行部が回っていて、左右のどちらかを入れていて、その側に有効な腕の設定がある間、又は校正で点を集めている間だけ `body.configure({ enabled: true })`。条件が同じなら `configure` を呼ばない（AT-04 は呼ぶたびに世代を上げるため、腕の動きの大きさを変えただけで履歴を捨てない）。
- **層**：腕の層は顔の層と同じ id `tracking` で別に出し、入れていて腕の設定がある側の腕のパラメータだけを持つ。顔のトラッキングを開始していない・顔が外れていても出る。
- **上書きの終わり**：フレームの後に、腕の層より上の層（表情・ホットキー・アニメーションなど）がその側の肩・肘・手首を**重み1で上書き**したかを見て、上書きの間は追従の出力を表示中の姿勢へ合わせ続ける（`resumeFrom`）。上書きが終わった次のフレームから、その姿勢から約200msで追従へつなぐので跳ばない。重みの小さい混ぜ合わせ・加算は上書きとみなさない。反対側には触れない。
- **ミラー**：対応付け・手形の `configure` と追従の `reset`（表示中の姿勢から休止を経て再取得）。左右を一度に入れ替えない。
- **校正**：`captureCalibration(step)` は撮影時刻で約1秒ぶんの Pose を集める。4秒で点が来なければ失敗（理由を出す）。右手の手順の後に `computeArmCalibration` を求め、成功すれば Environment へ保存して対応付けと追従をやり直す。失敗なら理由を `invalid` で返す。`cancelCalibration` は途中の記録を捨て、待っている呼び出しを何も保存せずに終える。
- **状態の通知**：姿勢の数値は毎フレーム変わるので、追従の状態・手の状態・手形・理由が変わったときだけ画面へ知らせる。診断は通知ごとに更新し、手だけの通知では前の Pose の点を残す。
- **古い世代**（v2）：新しい世代の後に遅れて届いた古い世代の通知は、サービスの入口で捨てる。追従だけでなく診断・校正の点も更新しない。
- **別のプロジェクト**（v2）：プロジェクトの id が変わったら、リグが同じでも対応付け・手形・追従の履歴と診断を捨て、途中の校正を何も保存せずに終える（待っている呼び出しも終える）。追従は今の姿勢から休止へ戻り始め、同じ世代でもこれから届く観測で取り直す。カメラ・体の推定は止めない。校正の結果（Environment）は残す。
- **切替の時刻**（v3）：プロジェクト・ミラー・校正を切り替えた時刻（撮影時刻と同じページの時計 `performance.now`）を下限にして、それより前に撮影した Pose・手は、同じ世代でも追従・手形・診断・校正の点に使わない（Pose と手は部分ごとに見る）。カメラを止めないので、切替の前に撮影した推定が後から届くため。
- **寿命**：実行部の `attach` の最初で体の推定を購読し、最後の解除で購読をやめて体の推定を止める。サービスを差し替えたときも解除する。`dispose`（v2）は最後の解除と同じく体の推定を止め、待っている校正を何も保存せずに終える。その後の `attach`・解除・`dispose`・観測・校正は何もしない（二重に解放しない）。

## 未確認・制約

- **実カメラでは動かしていない**（仮の体の点だけ）。実カメラの推定・遅延・自然さは AT-14・16。
- 別のプロジェクトかどうかは `Project.id` で見る（実行部の物理・アニメーションと同じ）。同じ id のプロジェクトを開き直したときは、リグが変わらなければ追従を続ける。
- Tauri のアプリ（本番の窓）では確かめていない。本番アプリへの反映はユーザーの指示のときに行う。
- 上書きの判定は「前のフレームの層」で行う。上書きが始まるフレームは、腕の層の値でなく上書きの値が表示されるので跳ばないが、上書きの重みが毎フレーム 1 と 1 未満を行き来する場合は、合わせる・合わせないが切り替わる。
- 手形は手の推定（AT-07）が手を見つけたときだけ更新し、見つからない間は休止形（AT-09 の約束）。
