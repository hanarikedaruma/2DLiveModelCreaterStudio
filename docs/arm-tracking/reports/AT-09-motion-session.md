## 約束

**流れ**：観測（`update`）ごとに、正規化した手首・肘（腕の長さ1）を撮影時刻でならし、モデルの上腕＋前腕の長さ（px）を掛けて IK を解く（手首の角度は後で決める）。描画（`tick(now)`）ごとに、手首の角度・動きの大きさを足した目標へ、角速度・角加速度を制限して近づけ、最後に静的制約へ収める。

**動きの大きさ（gain）**：休止姿勢からの関節の量に掛ける（0で休止姿勢、1でそのまま、2で2倍。最後に可動域へ収める）。位置ではなく関節空間で掛けるので、届かない目標を作らない。

**手首**：AT-07の掌の軸（肩の座標）の向きを「下向き0・外向きが正」の角度にし、前腕の向きを引いた相対角を手首にする（可動域で止まる）。掌の軸が無くなったら、その相対角を200ms保ち、500msで休止の手首へ戻す。腕は止めない。

**状態**（左右別。時間は最後に有効だった観測の撮影時刻から測る）：

| 状態                 | 条件と動き                                                                                                                            |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `tracking`           | 最新の観測が有効。肘も見えている                                                                                                      |
| `inferred`           | 最新の観測が有効で、肘だけ見えない（固定した曲がる側と前回の姿勢でIK）                                                                |
| `holding`            | 最新の観測が無効（見えない・左右が決まらない）。最後の有効から200msまで、最後の姿勢を保つ（外挿しない）。この間に有効へ戻ればすぐ追従 |
| `returning`          | 最後の有効から200ms後（観測が止まった場合も）。500msで関節空間を休止姿勢へ戻る                                                        |
| `rest`               | 休止姿勢と休止形。値は出し続ける（重みを0にしない）                                                                                   |
| `recovering`         | 戻っている・休止の間に、同じ側の有効な観測が撮影時刻で100ms続いた。今の姿勢から200msで追従へつなぐ                                    |
| `off`・`unavailable` | 設定で切った側／リグが無い・無効・IKが不正と返した側。値を出さない（どちらの側も出さなければレイヤーを出さない）                      |

同じか古い撮影時刻の観測は捨てるので、再通知で保持を延ばさない。1回の描画で進める時間は50msまで、時刻が戻っても進めない。

**手形**：AT-07の確定した形（`confirmed`・`confirmedAt`）を使い、120msの確定待ちは繰り返さない。確定した形の最後の観測から250ms以内は「追従」、500msまで「保持」、過ぎたら設定の休止形。腕が戻っている・休止のときも休止形。固定（`handMode`）なら腕に関係なく固定の形（`fixed`）。重みは選んだ形だけ1、他は0。

**リセット**：`reset(generation, displayed?)` で観測の履歴・フィルタ・手形を消す。`displayed`（今表示している値）があれば、その姿勢から休止へ戻り始め、観測が続けば復帰でつなぐ（アニメーションの終わり・ミラーの切替で跳ばない）。観測の世代が上がったときも同じく休止へ戻り始め、再取得してからつなぐ（ミラーを変えた直後に両腕が入れ替わって跳ばない）。古い世代の観測は受け付けない。`configure` でリグが変わった側・追従を切った側は休止姿勢から始め直す。

### ならしと遅れ（試験と同じ条件：観測30fps、撮影から届くまで40ms、描画60fps。肩 ±30°の手振り）

| なめらかさ  | 1Hzの遅れ（このセッション分） | 2Hzの遅れ | 振幅（1Hz／2Hz） | 静止中の揺れ（肩の標準偏差、観測に±0.01の揺れ） |
| ----------- | ----------------------------- | --------- | ---------------- | ----------------------------------------------- |
| 0           | 38ms                          | 37ms      | 98%／94%         | 0.56°                                           |
| 0.5（既定） | 48ms                          | 42ms      | 97%／92%         | 0.38°                                           |
| 1           | 54ms                          | 44ms      | 96%／91%         | 0.25°                                           |

遅れは、撮影から表示までのうち、観測が届いてからこのセッションが足す分（届くまでの40msを除く）。なめらかさ0でも約37msあるのは、30fpsの観測の間の待ち（平均約17ms）と、角加速度の制限による減速のため。設計の目標（撮影から表示まで p95 100ms 以下）に対し、推定に40msかかるなら既定で約90ms。実機の遅れはAT-14で測る。
