# 顔の上下と、口をすぼめた形の認識（調査と設計）

2026-10-12 CL。ユーザーの指摘（課題は I-083）。カメラを使う確認は CL ではできないので、まず値を見る道具を足し、ユーザーに実際の値を見てもらってから直し方を決める。末尾の「決めてほしいこと」の答えをもらってから実装する。

## 解決したいこと

ユーザーの言葉:

> 顔の上下がうまく認識されていない気がする。口をすぼめている形を認識できていない気がする。

1. 顔を上下に向けたとき、モデルの顔がはっきり上下を向くようにする。
2. 口をすぼめた形（「う」「お」の口）を認識して、モデルの口に出す。

## 今の作り（コードで確かめたこと）

### 流れ

カメラ → MediaPipe の顔の推定（`packages/tracking/src/source/landmarker.ts`。顔の向きの行列と、表情の値 52 個）→ トラッキングの値に直す（`source/convert.ts`）→ 校正（正面の向きを引く）→ 左右反転 → 範囲で切る → なめらかにする（One Euro）→ パラメータへ割り当てる（`mapping/producer.ts`）→ プリセットの不感帯と強さ → パラメータの範囲で切る。

### 顔の上下

| 項目         | 今の作り                                                                                                                                                                                  |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 角度の求め方 | 顔の向きの行列から、上下の角度を度で出す（`convert.ts` の `matrixToAngles`）。上向きが正                                                                                                  |
| 割り当て     | 顔の上下 −30〜30° を FaceAngleY −30〜30 へ、そのまま（1:1）（`mapping/defaults.ts`）                                                                                                      |
| 校正         | 正面を向いたときの上下の角度を引くだけ。上下の振れ幅は測らない（`mapping/calibrate.ts`）                                                                                                  |
| このPCの設定 | 校正は済んでいる（正面の上下 −4.4°）。プリセットは「カスタム」で、強さ 0.9・不感帯 1.5°・なめらかさ 0.51（「安定」に近い。`%APPDATA%\jp.co.globalsystems.live2dstudio\environment.json`） |
| モデルの動き | かんたんセットアップの頭の向き（head-pose）は、FaceAngleY ±30 で目鼻口が最大 14° 分だけ動く（`core/src/setup/headPose.ts` の `HEAD_LIMIT.maxPitch`）。あごと頭の上は動かない              |
| 体           | 上下の向きで体（BodyAngleY）は動かない（`core/src/layers/bodyFollow.ts` は左右と傾きだけ）                                                                                                |

画面に向かってうなずくときの上下は、ふつう ±10〜15° くらい。今の設定で 10° うなずくと、不感帯と強さ 0.9 で FaceAngleY は約 8 になり、モデルでは目鼻口が約 3.8° 分動くだけになる（左右は上限が 25° なので、同じ 10° で約 6.7° 分動く。上下は左右の 6 割に見える）。MediaPipe の上下の角度は、左右より小さめ・不安定に出やすいとも言われるが、このアプリでは実際のカメラで測っていない。

### 口をすぼめた形

| 項目         | 今の作り                                                                                                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 使う表情の値 | 口の横幅 = 口を横に引く（mouthStretch の左右の平均）− すぼめる（mouthPucker）（`convert.ts`）。口を前に突き出す「お」の形（mouthFunnel）は使っていない                   |
| パラメータ   | MouthWidth（−1 すぼめる 〜 +1 横に広げる）だけ。すぼめた丸い口・突き出した口のパラメータは無い                                                                           |
| モデルの動き | かんたんセットアップは MouthWidth −1 で唇と口の中を横に 0.75 倍にするだけ（`core/src/setup/step1.ts`）。縦の形・丸さは変わらない。ユーザーのモデル（cardigan）は 0.82 倍 |
| 声の母音     | 声から「う」「お」を推定すると、MouthWidth を −1・−0.7 にする（話している間だけ）                                                                                        |
| 校正         | 口は「大きく開ける」だけ。すぼめた形は測らない                                                                                                                           |

すぼめる値（mouthPucker）は、実際には 1 よりかなり小さく出ることが多い（測っていない）。たとえば 0.4 なら、口の横幅は 0.9 倍ほどにしかならず、見て分からない。

## 考え方

### 第1段階: 値を見る（直す前に、どこで弱くなっているかを分ける）

スタジオのトラッキングの節に「生の値」の表示を足す（D1）。カメラの値（顔の上下・左右の角度、口を開ける・横に引く・すぼめる・突き出すの値）と、割り当てた後のパラメータの値を並べて、動きに合わせて棒で見せる。ユーザーにうなずいたとき・口をすぼめたときの値を見てもらい、次の3つのどれが原因かを決める。

1. カメラの値そのものが小さい（MediaPipe の限界）。
2. 割り当て・強さ・不感帯で小さくなっている。
3. モデルの動きが小さい（値は届いているのに、絵があまり動かない）。

### 第2段階: 直す（第1段階の結果で選ぶ。候補）

**顔の上下**

- **上下の感度**: トラッキングの節に「上下の感度」を足す（左右・傾きとは別）。既定は、顔の上下 ±15° を FaceAngleY ±30 にする（今の2倍）。（D2）
- **上下の校正**: 校正に「上を向く」「下を向く」を足し、その人の振れ幅に合わせる。上と下で幅が違ってもよい（カメラが上にあると、下向きが狭くなりやすい）。（D3）
- **モデルの動き**: かんたんセットアップの頭の上下の量（今 14°）を増やし、頭全体を少し上下にずらす。体も少しついてくる（BodyAngleY）。I-067（顔の左右の向き）の直しと合わせて行う。（D4）

**口をすぼめた形**

- **突き出す値も使う**: すぼめる量を「すぼめる（mouthPucker）と突き出す（mouthFunnel）の大きいほう」にし、感度を掛ける（既定 2 倍）。（D5）
- **すぼめた口の校正**: 校正に「口をすぼめる」を足し、その人のいちばんすぼめた値を 1 にする。（D6）
- **モデルの動き**: MouthWidth −1 の形を強くする（横 0.6 倍、縦に少し伸ばして丸くする）。（D7）
- **新しいパラメータ**（後で）: 「口をすぼめる」（MouthPucker）を別に持ち、丸く突き出した口の形を作る。STEP4 の候補（カード88）と合わせる。（D8）

## テストと確認

- 単体: すぼめる値の求め方（突き出す値・感度）、上下の感度、上下で幅の違う校正。
- 画面: ユーザーにカメラの前でうなずく・口をすぼめるをしてもらい、生の値と、直した後のモデルの動きを見てもらう（CL はカメラを使えない）。
- 今の割り当て（カスタムの割り当てを含む）を使っているプロジェクトの動きが、感度を変えない限り変わらないこと。

## 完成の条件

- 画面に向かって自然にうなずくと、モデルの顔がはっきり上下を向く。
- 口をすぼめると、モデルの口がすぼまる（見て分かる）。
- 生の値を見て、カメラの限界か、設定か、モデルかを分けられる。
