## I-039の扱い

既存の共通headRootワープは、顔と髪のずれに対する暫定対応であり、この到達点の完了にはしない。課題表の状態を未着手へ戻したが、従来の対応記録・コード・画像は削除していない。初回6件と今回のカメラ/ホットキーの修正で頭部の自動生成は変更していない。

- headRootを共通姿勢の基準とし、faceGroupとhairGroupは別にする。「共通の向き」と「全画像へ同じワープ」は区別する。
- 共通姿勢と簡易奥行きから初期変形を求め、既存の2Dキーによる方向別補正で自然なイラスト表現に仕上げる。
- 描かれている隠れた部分は露出できるようにする。未描画の側面は素材として用意し、変形だけで未知の絵が得られるとは扱わない。
- ユーザー指定の狭い回転範囲を前提に、鼻先と実際の輪郭、髪の隙間、目、首の接続からモデルごとの限界を設定する。一律12度・6度を完成仕様にはしない。
- 左・正面・右の3姿勢を比較し、全体の横移動を除いても輪郭と顔の特徴の位置関係が向きを表すことを確認する。その後に上下・斜め・連続運動と物理ON/OFFを検証する。
- 移動量や画素の重心の変化だけを合格条件にしない。方向別の手動修正・ロック・Undo/Redo・保存/再読み込みも確認する。
