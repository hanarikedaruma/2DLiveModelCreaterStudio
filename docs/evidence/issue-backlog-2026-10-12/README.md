## 再確認のコマンドと作業用スクリプト

通常の環境では `pnpm test`・`pnpm typecheck`・`pnpm lint`・`pnpm format:check`。この環境ではローカルにあるpnpmを直接実行した。

```powershell
node .cache/corepack/v1/pnpm/9.15.4/bin/pnpm.cjs -r --workspace-concurrency=1 test
node .cache/corepack/v1/pnpm/9.15.4/bin/pnpm.cjs -r typecheck
node node_modules/eslint/bin/eslint.js .
node node_modules/prettier/bin/prettier.cjs --check .
```
