# 冒頭の「あ」を息に近づける（2026-10-16）

［恥ずかしい］の言い出しを「ぁあっ」とはっきり伸ばすのではなく、口を開いて息が漏れるような、ごく薄い声の混ざる短い音へ近づけた。合成モデルは既存のQwen Base、参照声・本文・声質設定も従来のまま。別の合成器へ切り替えない。

## 変更

- 合成された文が、独立した「あ、」「ぁっ……」等で始まる場合だけ対象。生成済みの冒頭音の響きからスペクトル包絡を推定し、非周期的な励振を主体にして短い息を近似する。声の原音は1.5%、息の近似成分は元の包絡の25%を使う。単に母音の音量を下げる処理ではない。[通常発声から囁きへの変換の研究](https://arxiv.org/html/1912.05289)を参考にした限定的な信号処理で、自然な呼吸の完全再現を意味しない。
- 最初の640ms内に、70〜320msの短い音と80ms以上の間を確認する。音の途中の明瞭な音量の谷・再上昇や響きの大きな変化があれば見送り、単語をまとめて息へ変えない。判別できない場合は生成音を保持する。
- 尺を変えず、対象音の前後は短く滑らかにつなぐ。通常の最初のPCM内で完結し、追加の先読み待ち・AIモデル・通信はない。元の文章から語を削除しない。入力本文・履歴は従来通り保持する。
- 全文・逐次の両方に同じ処理を使い、他の感情には適用しない。入力中の先行生成にも適用し、送信時に同じ結果を再利用する。
- 入力済みの「ぁっ・・・」や「だっ……」を、もう一度自動で増やさないよう判定を直した。保存形式・公開API・参照声のキャッシュキーは変更していない。

今回の音声は0.07〜0.33秒だけを処理し、それ以降の本文はサンプル単位で完全一致、全体の長さも同じ3.60秒。冒頭の周期性の指標は0.905→0.097で、有声音を大きく減らした。[測定](onset-measurement.json)。これは音の構造の指標で、自然さの聴感評価とは別。

Whisper-smallによるローカルの独立した内容検査では「あなたのことが大好きです」と認識され、本文が一致した。期待する台詞は認識器へ渡していない。[結果と音声SHA-256](content-check.json)。認識一致だけで演技の自然さや声の完全な同一性を保証するものではない。

- 実機の対象区間も0.07〜0.33秒。追加処理は逐次2.705ms／全文2.362ms、逐次の再バッファ0回。同じ話者hashと原文履歴を確認した。[逐次](stream-shy.json)・[全文](whole-shy.json)・[感情切替](stream-cheerful.json)・[先行生成](prefetch.json)。これらの処理時間は合成全体の時間ではない。
- 本番ビルドが成功し、通常のアプリへ反映。実行ファイル・追加した`speech_onset.py`を含む13ファイルのSHA-256を照合した。[配置記録](installed.json)。本番には検証用の画面フックが含まれない。

声の震え・強弱・文中や語尾のブレスを全面的に実装した変更ではない。今回の調整は言い出しの「あ」に限定する。
