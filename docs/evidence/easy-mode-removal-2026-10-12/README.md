# I-088 表示の「かんたん／詳細」の廃止と検証

2026-10-12 CO。ユーザーの「次」の指示を受け、[計画](../../issue-backlog-plan.md)のI-088を実装した。[採用仕様](../../easy-mode-removal-design.md)、契約はCC-019。ProjectとschemaVersion 7は変更していない。

## 実装したこと

- ヘッダーの表示段階、`UiLevel`・Environment/EditorStateの`uiLevel`・登録の`level`・`DetailDisclosure`を廃止した。旧「詳細」のワープ、生成方式、トラッキングの割り当て、数値設定を直接使える。
- 方向グリッドと任意の組み合わせは「組み合わせの補正」の節で選ぶ。グリッドの編集・ロック・自動に戻す操作を保ち、断面のパラメータを保持する既存の動作も維持した。
- マスクの単一選択欄を外し、複数のマスク元と反転の欄を最初から表示する。
- 手動で追加・編集したキーを常にロックする。変形・不透明度・メッシュ・ワープの既存キーと新しいキーを保護する。明示的なロック解除、基準の自動キー・格子の補助キーは従来どおり。
- セットアップの処理を保ち、ボタン・説明・Undoの名前を［自動セットアップ］に統一した。
- 古いenvironment.jsonの`uiLevel`は無視し、他の正常な設定を保つ。保存時には旧項目を含めない。UC-16・関連の手動確認手順と開発の手引きも更新した。

## 自動検証

- 全10パッケージのテストが成功。デスクトップは166ファイル・1,358件、schemaは11ファイル・98件。
- 新規4件: 旧uiLevelを形・値によらず破棄するschemaの1件と、変形・メッシュ・ワープの追加/編集キーをロックし、再補間で同じキーを残す3件。既存の不透明度・組み合わせ・範囲再補間・Undoのテストも新しい保護仕様で成功した。
- 表示段階専用の3テストファイルを廃止し、表示のテストは「最初から使える」に移行した。プリセットの個別調整を上書きする確認は維持した。
- 全パッケージとe2eの型検査、全体ESLint・Prettier、`git diff --check`が成功。製品コードにuiLevel・DetailDisclosure・出し分けの参照が残っていないことを検索で確認した。
