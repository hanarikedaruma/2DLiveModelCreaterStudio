# 恥ずかしい演技の出だし・語尾・間・テンポ（2026-10-16）

ユーザー指定を実装へ反映した確認記録。新しい試聴用WAVは作成しない。以前の4母音サンプルは実際には`style='shy'`で生成しており、感情なしの音声ではなかった。ただし当時の処理はつまり音の吐息が中心で、本文の出だし・語尾・広い間・遅いテンポまで反映した演技全体の確認には不十分だった。

## 実装

- `speech_shy.py`を全文・逐次・先行生成に共通で使用する。独立した冒頭音の従来の変換式は保持し、その音と響きが合う本文の最初の母音も短く息へ近づける。「い（息）、い（息）きます」「う（息）、う（息）ん」を対象とする。本文の母音は最大120ms、判別不能なら見送り、続く子音・単語全体を無声化しない。
- つまり音と本文の間はテンポ調整前650ms以上。後の88％テンポを含め約0.7秒以上の目安となる。十分に間がある生成へ追加で固定の長い無音を重ねない。
- 子音のつまり音でも、書かれた短い言い直しと次の言葉の間を判別できれば間を広げる。この場合は本文の子音を息に変えない。
- 句末・文末で最大180msを使い、声から息へ滑らかに移して減衰する。長い自然な間と発話終了を処理し、既に息にした出だしを二重に弱めない。対象区間の前後を滑らかにつなぐ。
- `speech_tempo.py`のWSOLAで通常の88％へ落とす。サンプルレートを下げる低速再生ではない。固定した入力窓・相関探索・重ね合わせを使い、入力パケットの分け方で結果が変わらないようにする。
- 話者の参照音声・合成モデル・声質設定は従来通り。効果を合成指示の追従だけに依存させず、実際のPCMへ適用する。強めた合成指示で「あ」の従来の判定が外れたため、合成指示は以前の安定したものを維持した。
- 音声の尺は間とテンポの分だけ増える。原文・履歴・文脈・保存形式は変更しない。出力に応じて再生バッファを見積もり、速度履歴も感情別にする。他の感情へ息・間・遅いテンポを残さない。

## 処理の確認

[処理検査](processing.json)は既存の実GPU生成音をメモリ内だけで処理した結果。4母音と既存の「あ」で本文の出だし・語尾・間・テンポを確認した。全文と137／1920／7680／15360サンプル単位の入力は完全一致。最初の「あ」の変換式単独の結果は承認済みSHA256と同じだが、演技全体は時間と対象PCMを意図的に変更する。

240Hzの基準音は約239.87Hzを維持し、72000フレームから81818フレームへ伸びた。これはテンポと高さの構造的な検査で、声や演技の聴感評価を代替するものではない。

境界を確実に決められない音を無理に息へ変えない。語尾は自然な間・文末を対象とし、形態素ごとのすべての単語の終わりを個別に解析する変更ではない。
