# 感情の縦並びボタンと「恥ずかしい」の口ごもり

2026-10-16。入力欄の左に感情を縦に並べ、［恥ずかしい］を選択して入力すると短く口ごもりながら発話する依頼への対応。

## 操作と構成

メイン・別入力窓の入力欄左に［おまかせ］［うれしい］［恥ずかしい］［やさしい］［寂しい］［驚き］［ささやき］を配置した。選択した一つを色と`aria-pressed`で示し、既存の`SpeechPreferences.style`として両画面で共有・保存する。`shy`を追加したが保存形式11・既存の感情値を維持した。再生中の設定変更の扱いは既存どおり。

入力中の150ms先行合成も同じ感情を使う。感情変更は古い下書き音声を無効にし、再合成する。準備済みの完全一致した音声は送信で再利用する。原文・履歴・直前発話の文脈は加工しない。

`speech_delivery.py`は、明示選択した`shy`だけに短い言い直し・ためらいを最大2箇所に加える。例:

```text
入力: あなたのことが大好きです
合成: あ、あなたのことが…だ、大好きです
```

言い出しの仮名は拗音・半角濁音を含めて一拍のまとまりで扱う。「大好き」「ありがとう」などの限られた表現は、読みが明確な音の言い直しを使う。曖昧な漢字・名前・日付の言い出しでは「あ……」のようなためらいにする。「今日は」を「こ、今日は」と誤って読み出すことを避ける。明示された言い直しは重ねない。否定を含む元の文の本体は維持する。他の感情では入力を加工しない。

追加の文章生成AI・辞書・通信・音声の部分コピーは使わない。演技を加えた全文を既存の同じ話者プロンプトで1回合成する。声質・フィルタ・ゲインも共通。逐次再生の音声長の見積もりと学習する読み上げ速度は、演技込みの文の長さを使う。別の話者を作る処理ではない。

## 実GPUの比較

RTX4050 Laptop 6GB、固定版Qwen Base 1.7B、同じ参照WAV・seed。モデルを温めた後に4回生成した。ここでの最初のPCMは生成時刻で、アプリの再生開始時刻とは分けて扱う。

| 同上 | 恥ずかしい | 3.60秒 | 4.041秒 | 0.852秒 | 0.047ms |

## 検証と限界

感情はユーザーがボタンで選択する。言い直しの位置は有限の規則で決めるため、一般的な意味理解による演技判断ではない。語句の言い直しと短い間は合成する文で指定し、照れた抑揚はモデルへ指示する。Baseは公式モデルカードのInstruction Control欄に対応の記載がないため、照れの自然さや演技の強さは試聴で判断する必要がある。[公式モデル説明](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base)。話者の参照hashが同じであることだけで、知覚される声質の完全一致を保証するものではない。

原文保持、既存感情の無加工、曖昧な読み、拗音・半角濁音、重複防止、否定文、長さ制限、話者プロンプト維持、演技込みのバッファ見積もりはPythonで検査する。画面では選択した感情の先行合成・切替後の送信、保存形式では感情の往復を検査する。実GPUのアプリでは左・縦の配置、両画面の共有、先行合成の切替と再利用、即送信・ミュート・履歴の原文保持・選択の保存を検査する。

Python101件、画面・サービス45件、保存形式7件、実GPUのTauri結合6件が成功。型・lint・整形も成功した。最終の実アプリ試験は、口ごもり付きの逐次再生が送信→実出力2.649秒、前処理0.077ms、途中の再バッファ0回。［うれしい］へ戻すと前処理による言い直し0箇所、再生開始1.800秒、再バッファ0回だった。この2件は直前発話の文脈が異なるため、厳密な同条件A/Bとは分ける。[即送信](stream-shy.json)、[うれしいへ戻す](stream-cheerful.json)、[準備済み音声の再利用](prefetch.json)。

画面: [別入力窓](emotion-input.png)、[メイン](emotion-main.png)。音声の出力時刻の試験で、WASAPIが通知する隣接バッファの時刻が一時的に重なる場合も検出した。機器時計による換算に加え、前のPCMの出力区間より前へ次の通知を戻さない処理を加えた。音声そのものを伸縮・反復する補正ではない。最終の全文・逐次試験ではミュート後PCMが0、有限値、時刻の逆転0を確認した。[全文](native-whole.json)、[逐次](native-stream.json)、[中断](cancel-stream.json)。

本番ビルドの検証用操作口が無いことを確認し、通常のインストール先へ反映した。実行ファイル、音声コード、実行設定、参照WAVなど12ファイルのSHA256を照合した（[配置記録](installed.json)）。ユーザーのアプリを終了させる操作は行っていない。
